### 신호 채택 기준

### 단계별 판정 — 여섯 신호를 모두 점검

아래의 ‘미확인’은 신호가 없다는 확정이 아니다. 각 단계에서 정보 재입력·대기·지연·품질 편차·한 사람 의존·데이터 단절·중간 차감 중첩의 여섯 신호를 검토했으며 모두 발생 근거 미확인이다. 이 문장에서 ‘대기·지연’은 하나의 신호다.

| 단계 | 자료에 실제로 있는 근거 문장·위치 | 신호 판정·채택하지 않은 이유 | 추가로 확인해야 할 자료 [I] |
|---|---|---|---|

### 기회 후보 매트릭스와 사분면

채택 신호가 없으므로 연결할 기회 후보도 0건이며 점수·사분면은 해당 없음이다. 첨부 완료기준에는 축·점수 척도·AI 기회 유형의 정식 목록이 없으므로 임의로 유형·점수·사분면을 만들지 않았다. 팀이 이미 선택한 제품 기획 기능을 비효율 신호의 검증된 해결책으로 바꿔 기입하지 않는다.

| 기회 ID | 연결 신호 ID | AI 기회 유형 | 매트릭스 축·척도 | 점수 | 사분면 | 상태 |
|---|---|---|---|---|---|---|

검증된 신호에서 기회 후보가 생기면 연결 신호 ID·팀의 평가 축·척도를 먼저 확정해 점수와 사분면을 작성한다. 현재는 평가 대상이 없으며 ‘고효과·고실현성’ 같은 판정을 붙이지 않는다.

## 🤖 우리 에이전트에 어떻게 쓸까?

- [아이디어] 후속 현장 기록·인터뷰·로그에서 실제 반복 입력·지연·결과 편차 등의 문장이 확인된 경우에만 관련 AI 기회를 검토한다. 신호 ID·근거·담당·검증 방법을 함께 연결한다.

## ⚠️ 광고 표현 체크

- 제품 효능·광고 문구를 제안하지 않았다. 리뷰의 반응을 제품의 의약품식 효능이나 공정 결함으로 일반화하지 않는다.

## 📌 다른 팀원에게

- 현재 검토 범위는 지정한 두 문서다. 추가 신호를 조사할 때는 위 ‘추가로 확인해야 할 자료’에서 실제 발생 사례와 출처를 확보한다. 특정 리뷰 파일의 제출을 현재 작업의 필수 조건으로 삼지 않는다.
- 실제 보드의 마커 목록·돈 라벨, 기회 유형 목록, 매트릭스 축·점수 기준은 아직 확인하지 못했다.

## ❓ 아직 모르는 것

- 실제 비효율 발생을 뒷받침할 운영 기록·인터뷰·표본과 지표 정의.
- 단계별 실제 비효율 발생 사례와 데이터 보유자·피드백 전달 여부.

- 보드 접근 위치·마커 후보, AI 기회 유형 분류와 매트릭스 평가 기준.

이 파일의 출처 번호는 독립적으로 매겼다. 원페이지 안의 원출처 번호와 혼동하지 않는다. 원페이지는 요약 문서이며, 여기 인용한 문장은 원페이지의 문장이다. 기업 원문을 새로 확인한 결과가 아니다.

AI가 제안한 후속 확인 자료 이름은 실증 출처로 취급하지 않는다. 첨부 이미지는 완료기준으로 사용했으며 기업 비효율 발생의 출처로 취급하지 않는다.

### 완료기준 점검

- [ ] 돈 시작점·공정·차감 라벨을 보드에 표시 — 문서에 근거·한계 정리, 보드 미접근.
- [x] 단계마다 확인할 데이터 이름·보유자·피드백 상태를 표로 표시 — 자료 이름은 `[I]`, 실제 보유자·피드백은 `[U]`. 실태 확인 완료를 뜻하지 않음.
- [ ] 마커 후보마다 신호 1개와 출처 연결 — 검증된 신호 0건, 보드 마커 목록 미확인. 후보를 임의 생성하지 않음.
- 기회 후보의 매트릭스 점수·사분면 기록 — 해당 없음: 신호 기반 기회 후보 0건. 후속 평가 시 축·척도 확인 필요.
- [x] 5단계 × 6종 신호의 채택 여부를 점검하고 미채택 이유·판정 참고 문장 기록.
- [x] 근거 없는 신호·AI 기회·점수를 생성하지 않고 `valuechain/signals.md` 저장.
- 커밋 여부는 Git 기록으로 확인한다. 지정 문서의 근거 점검·저장을 마친 결과이며, 보드 작업과 실제 운영 자료 검증까지 수업 전체가 완료됐다고 판정하지 않는다.
