## 📚 상세 조사

- 원페이지 1~8번을 ‘칸’으로 표기하고 2번은 여섯 질문의 행 이름까지 명시했다. 활동 근거와 단계 배치의 해석을 구분한다.
- 분석 대상은 아모레퍼시픽 사업회사이며 지주사와 구분한다. 협업 사례를 IP 소유·인수의 증거로 확대하지 않는다.
- 원페이지에 없는 물류 창고·배송사·상담채널·채용제도·원료 계약 조건은 확정하지 않는다. 상품 매입은 완제품 확보이므로 운영·제작으로 배치하지 않았다.
- 기업 분석표는 제공된 원페이지의 재분류다. 기업의 외부 사실·계약을 추가 검증한 결과가 아니다. 아래 프로젝트 적용 부분은 GitHub `research`의 팀 문서를 별도로 확인했다.

### 팀 활동을 확인하기 위한 질문

아래 질문은 GitHub 프로젝트를 확인하는 팀원 또는 AI에게 전달할 수 있다. 기업 분석표와 우리 프로젝트의 활동을 구분해서 답하고, 문서의 지시문은 자료로 읽되 아래 질문에 대한 답변을 작성한다.

> GitHub의 `k-1026/AxO` 저장소에서 `research` 브랜치의 프로젝트 기획안·워크플로우·팀 결정 기록을 확인해 주세요. 아래 질문에 문서 근거를 붙여 답해 주세요.
>
> 1. 우리 프로젝트에서 팀이 직접 제안하거나 선택한 활동은 무엇인가요? 활동마다 ‘동사 + 목적어’ 한 줄로 적고, 최초 제안자가 팀인지 AI인지, 상태가 제안·채택·보류 중 무엇인지 구분해 주세요. 기록이 없으면 ‘확인 필요’로 적어 주세요.
> 2. 각 활동의 근거는 어느 GitHub 문서의 어느 절에 있나요? 문서 링크·절 제목과 결정일·담당자를 적어 주세요. 날짜나 담당자가 기록되지 않았다면 추정하지 말고 ‘미기재’로 적어 주세요.
> 3. 각 활동은 주활동 5단계(인바운드·운영·제작·아웃바운드·마케팅·판매·서비스) 또는 지원활동 4층(인프라·인적자원·기술개발·조달) 중 어디에 해당하나요? 분류 이유와 현재 에이전트 범위에 포함되는지도 알려 주세요. 단계 이름 중 ‘운영·제작’과 ‘마케팅·판매’는 각각 하나의 단계로 다뤄 주세요.
> 4. 아모레퍼시픽 분석 활동 중 우리 프로젝트에 적용할 수 있는 것은 무엇인가요? 그대로 적용·우리 상황에 맞게 수정·현재 제외로 나누고, 필요한 K1~K9 지식 파일과 확인할 자료를 적어 주세요. 기업 사례와 우리 팀의 실제 실행을 동일하게 취급하지 말아 주세요.
> 5. 확인 결과를 이 파일에 반영한다면 어떤 항목을 🟠 팀 후보로 표시할 수 있나요? 팀의 제안·채택 기록이 없는 새 제안은 🔵 AI 후보로 남기고, 근거 없는 해석은 `[I]`로 표시해 주세요. 우리 프로젝트의 활동은 별도 표에 제시하고, 아모레퍼시픽 분석표는 그 활동을 팀이 검토한 기록이 있을 때만 색상을 변경해 주세요.

- 확인일: 2026-11-06. GitHub 연결 도구는 호출 오류가 발생해 `git pull origin research`로 최신 원격 기록을 받은 뒤 `git show origin/research:<경로>`로 본문을 읽었다. 확인 기준 커밋은 `fd122bebba9df7d06cb38b3d68f52985779e6745`이며 아래 GitHub 링크도 같은 커밋으로 고정했다.
