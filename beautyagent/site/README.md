# 청향 출시 기획실 · 자체 사이트

GitHub 미리보기(htmlpreview) 대신 우리 컴퓨터에서 직접 띄우는 사이트예요.
트렌드 수집기가 서버 안에서 쉬지 않고 돌아요.

## 실행

```bash
node beautyagent/site/server.js
```

- 주소: http://localhost:8790
- 설치할 것은 없어요 (Node 기본 모듈만 써요).
- 같은 와이파이의 팀원도 보게 하려면 `beautyagent/site/.env`에 `HOST=0.0.0.0`을 넣어요.

## 트렌드 수집

| 출처 | 키 | 간격 | 등급 |
|---|---|---|---|
| Google 뉴스 RSS (약재 12종 + 일반 검색어 4개) | 필요 없음 | 4초마다 1건, 64초에 한 바퀴 | 🟡 |
| 네이버 뉴스 검색 API | 네이버 키 | 8초마다 1건 | 🟡 |
| 네이버 데이터랩 검색어 트렌드 | 네이버 키 | 15분마다 (하루 호출 1,000회 한도 안) | 🟢 |

- 네이버 키는 `beautyagent/site/.env`에만 넣어요. 예시는 `beautyagent/site/.env.example`에 있고, `.env`는 커밋되지 않아요.
- 브라우저는 SSE로 새 기사를 바로 받아요. "마지막 요청 N초 전"은 1초마다 바뀌어요.

## 저장되는 파일

| 파일 | 내용 |
|---|---|
| `idea/trend/live/news.jsonl` | 처음 본 기사를 한 줄씩 쌓아요 (지우지 않음) |
| `idea/trend/live/fetch_log.jsonl` | 요청마다 성공·실패를 쌓아요 |
| `idea/trend/live/state.json` | 지금 집계예요 (약재별 언급, 피부 고민 낱말, 최신 기사) |
| `idea/trend/trend.json` | 데이터랩 판정이에요 (키가 있을 때) |
| `idea/trend/트렌드스냅샷_YYYY-MM-DD.md` | 하루에 1개 만들고, 10분마다 다시 써요 |

## 화면에서 바뀐 것

- **실시간 뷰티 트렌드**
  - 수집된 숫자로 기획 포인트를 최대 4개 만들어요: 뜨는 원료, 떠오르는 피부 고민, 검색 흐름, 조용한 빈자리.
  - 기사 제목은 근거 링크로만 보여 줘요.
- **📈 뜨는 원료** 기준은 두 가지로 봐요:
  - 기사 언급 흐름 (실시간)
  - 데이터랩 검색 흐름 (키가 없으면 '확인 필요' 범위로 남아요)
  - 점수 구간은 가정이에요.
- **추천 폭** (고정 / 조금 넓게 / 넓게)과 **🎲 다른 추천 보기**는 같은 규칙 안에서 결과를 다양하게 바꿔요.
  - 필수 통과 조건과 기준은 그대로예요.
  - 바뀌는 것:
    - 기준 비중을 흔들어요.
    - '확인 필요' 칸은 점수 범위 안에서 뽑아요.
    - 계절에 맞는 다른 피부 목적을 시도해요.
    - 위 3개 후보는 피부 목적이 겹치지 않게 해요.
  - 추천 번호가 같으면 결과도 같아요.
