# 출시 기획실 사이트 말투 (톤앤매너)

- 담당: MEJ
- 대상 사이트: https://cosmeticai.vercel.app/
- 사용자: 신생 한방뷰티 브랜드 기획자
- 최종수정: 2026-11-20
- 상태: 초안 (팀 검토 전)

## 1. 말투 한 줄 정의

**"근거를 챙겨 주는 친절한 사수"**

전문성과 친근함의 비율은 70 : 30이에요. 차분하고 정직하게 말하고, 다음에 할 일을 먼저 알려 줘요.

## 2. 왜 이 말투인가

| 사용자 상황 | 필요한 것 | 말투에 반영할 점 |
|---|---|---|
| 경험이 적어 무엇부터 할지 모름 | 다음 할 일 안내 | **안내형**: "먼저 ○○부터 보세요" |
| 한방·성분·광고 규제 용어가 낯섦 | 쉬운 설명 | **풀어 쓰기**: 전문용어 뒤에 한 줄 설명 |
| 광고 표현 규제가 걱정됨 (`research/MEJ_공개VOC_기획자불편.md`) | 위험을 먼저 짚어 주기 | **솔직함**: "이 표현은 쓰면 안 돼요" |
| 혼자 결정해야 해서 불안함 | 결정의 근거 | **근거형**: 숫자와 출처를 함께 제시 |

> 너무 귀여우면 신뢰가 떨어지고, 너무 딱딱하면 초보 기획자가 주눅 들어요.

## 3. 규칙

- **해요체**를 써요. 예: "추천해요", "확인이 필요해요"
- **결론을 먼저** 말하고, 이유는 뒤에 붙여요.
- **한 문장에는 정보 하나**만 담아요.
- **전문용어는 처음 나올 때 풀어 써요.** 예: SOM(실제로 얻을 수 있는 시장)
- **약재 이름은 한글(한자)**로 써요. 예: 당귀(當歸)
- **모르는 건 모른다고** 말해요. 예: "확인이 필요해요"
- **과장하지 않아요.** "무조건", "대박", "완벽" 같은 말과 느낌표를 쓰지 않아요.
- **이모지는 상태 표시에만** 써요. 예: ✅ ⚠️
- **효능 표현은 화장품 범위 안에서만** 써요.
  - 써도 되는 표현: "진정에 도움", "촉촉함", "윤기 있어 보이는"
  - 쓰면 안 되는 표현: "치료", "염증 완화", "혈액순환 개선"

## 4. 화면별 예시

| 화면 | ⭕ 이렇게 | ❌ 이렇게 말고 |
|---|---|---|
| 추천 결과 | "겨울엔 크림 중심 라인을 추천해요. 보습 관심이 높은 계절이라서요." | "겨울엔 무조건 크림이죠!" |
| 근거 표시 | "가격은 올리브영 같은 용량 제품 기준이에요." | 출처 없는 숫자만 표시 |
| 데이터 없음 | "이 수치는 아직 확인이 필요해요." | "정보가 없습니다." |
| 다음 단계 안내 | "원료를 고르면 가격대를 계산해 드려요." | "다음 단계로 진행하세요." |
| 광고 표현 경고 | "'염증 완화'는 의약품 표현이라 쓸 수 없어요. '진정에 도움'으로 바꿔 보세요." | 효능 문구를 그대로 제안 |
| 오류 | "트렌드 자료를 불러오지 못했어요. 저장된 자료로 먼저 보여 드릴게요." | "Error: fetch failed" |
| 버튼 | "기획안 보기", "다시 추천받기" | "Submit", "확인하시겠습니까?" |

## 5. 적용할 곳

- 사이트 화면 문구: 추천 결과, 근거, 안내, 오류 메시지, 버튼
- AI Chat 지시문: `api/chat.js`, `server/gemini.js` (이 저장소 main 브랜치의 사이트 소스)

## ❓ 아직 정할 것

- 사용자 범위(신생 초보 / 방향이 확고한 사용자)가 확정되면, 전문용어를 풀어 쓰는 정도를 다시 맞춰요.
- 사이트명이 정해지면 이름과 말투가 어울리는지 함께 확인해요.
