# 에이전트 요금 구조 제안

## 📌 한 줄 요약
소액 월 구독(₩29,000, 기획서 5건)과 건당 이용권(₩14,900)을 함께 두면, 인프라·결제 고정비 기준으로 구독자 5명이면 손익분기점을 넘는다.

## 🔑 핵심 내용
- [사실] 경쟁 상대 매니패스트는 무료 플랜과 월 $20(Pro), 월 $60(Team) 구독에 크레딧을 붙이는 구조다 [1]
- [사실] 우리가 쓸 Supabase Pro는 월 $25, Vercel Pro는 월 $20부터다 [2][3]. Vercel 무료(Hobby) 플랜은 비상업용으로만 쓸 수 있다 [5]
- [사실] 토스페이먼츠 카드 결제 수수료는 3.4%(부가세 별도)이고, 가입비 22만 원과 연관리비 11만 원이 든다 [7]
- [해석] 인프라·결제 고정비는 월 약 ₩75,000이고, 기획서 1건의 Claude API 비용은 약 ₩500~1,500으로 추정된다 [2][3][4][7]
- [해석] 작은 뷰티 브랜드는 신제품 기획을 1년에 몇 번만 하므로, 순수 구독은 해지가 잦고 순수 건당 요금은 수익이 들쑥날쑥하다
- [아이디어] 구독과 건당 이용권을 함께 운영하고, 구독 가격은 매니패스트 Pro와 같게 맞춰 "같은 가격에 뷰티 전용"으로 비교한다
- [해석] 월 구독은 1건 단가 ₩5,800으로 가장 싸 보이면서 결제 1번당 이익(약 ₩17,900)도 가장 커서 대표 상품으로 홍보한다

## 📚 상세 조사

### 1. 경쟁 상대 매니패스트 요금제 (2026-11-16 확인)

| 플랜 | 가격 | 주요 내용 |
|---|---|---|
| Starter | 무료 | 가입 시 5,000 크레딧, 매일 3,000 크레딧, 프로젝트 3개, 내보내기 프로젝트당 3회 |
| Pro | 월 $20 (5배 사용량 $100) | 월 100,000 크레딧 + 매일 3,000 크레딧, 최대 3좌석, 고급 AI 모델, 내보내기 무제한 |
| Team | 월 $60 (5배 사용량 $140) | 월 100,000 크레딧 + 매일 3,000 크레딧, 기본 5좌석, 1명 추가마다 월 $10 |

- [사실] 연간 결제는 최대 25% 할인이다 [1]
- [해석] 구독에 크레딧을 붙이고, 많이 쓰면 더 높은 사용량 단계를 사는 구조다 [1]

**크레딧 작동 방식 (요금제 페이지 FAQ)**
- [사실] 크레딧은 AI로 문서를 만들거나 다듬을 때 쓴다 [1]
- [사실] 월간 결제는 결제일마다 월 크레딧이 새로 채워지고, 남은 월 크레딧은 이월되지 않는다 [1]
- [사실] 연간 결제와 제휴 플랜은 월 크레딧을 매달 주고, 남은 크레딧은 구독이 갱신되거나 끝날 때 초기화된다 [1]
- [사실] 크레딧을 다 쓰면 크레딧 팩을 따로 살 수 있고, 산 크레딧은 플랜 크레딧을 먼저 다 쓴 뒤에 쓰인다 [1]
- [사실] 작업별 크레딧 소모량(PRD, 와이어프레임 등), 크레딧 팩 가격, 매일 주는 크레딧의 이월 여부는 요금제 페이지에 없다 [1]
- [해석] 우리 요금제도 "남은 건수는 이월하지 않음"으로 정하면 매니패스트와 같은 방식이 되어 설명하기 쉽다

| Claude API (기획서 1건) | 약 ₩500~1,500 | 추정치. 넉넉하게 **건당 ₩2,000**으로 잡음 |
| 결제 수수료 | 결제액의 약 3.74% | 토스페이먼츠 카드 3.4% + 부가세 10% [7] |

**기획서 1건 API 비용 추정 방법**

- [사실] Claude 모델 가격 (100만 토큰당) [4]

  | 모델 | 입력 | 출력 | 캐시 쓰기 (5분) | 캐시 읽기 |
  |---|---|---|---|---|
  | Sonnet 5.5 | $2 | $10 | $2.50 | $0.10 |
  | Opus 5.5 | $4 | $20 | $5 | $0.20 |
  | Haiku 5.5 (입력 10만 토큰 이하) | $0.10 | $0.50 | $0.125 | $0.01 |

- 가정한 사용량은 다음과 같다 (Sonnet 5.5 기준)
  - 처음 작성: 지식 파일 약 6만 토큰을 캐시에 쓰며 입력($0.15), 생각 과정 포함 약 2만 토큰 출력($0.20) → 약 $0.35
  - 수정 요청 평균 3회: 회당 캐시 읽기 약 7만 토큰($0.007), 새 입력 약 5천 토큰($0.01), 출력 약 5천 토큰($0.05) → 회당 약 $0.07, 3회 약 $0.20
  - 광고 표현 검수: 작은 모델(Haiku 5.5)로 처리 → 거의 0
  - 합계 약 $0.55 ≈ ₩800
- [해석] Opus 5.5를 쓰면 입력·출력 단가가 2배라 비용도 약 2배가 된다 [4]
- [사실] Claude 4.7 이후 모델은 같은 글을 이전 모델보다 약 30% 많은 토큰으로 센다 [4]. 위 토큰 수는 어림값이라 실제로 재야 한다
- [해석] 실제 비용은 프로토타입으로 몇 건 돌려 재 봐야 한다. 재시도·긴 수정까지 생각해 건당 ₩2,000으로 넉넉하게 잡았다

### 3. 결제 대행(PG) 수수료 비교 (2026-11-16 확인, 부가세 별도)

| 항목 | 토스페이먼츠 [7] | KG이니시스 [8] |
|---|---|---|
| 신용·체크카드 | 3.4% | 3.0~3.5% (가맹점 형태에 따라 다름) |
| 계좌이체 | 2.0% (최저 200원) | 1.8~2.0% (최저 200원) |
| 가상계좌 | 건당 400원 | 건당 300원 |
| 간편결제 | 3.4% (일부 서비스 추가 수수료) | 3.0~3.5% (Apple Pay 3.5%) |
| 가입비 / 연관리비 | 22만 원 / 11만 원 (계약 형태에 따라 다름) | 요금 안내 페이지에 없음 |

- [사실] 토스페이먼츠는 영세·중소 사업자 카드 수수료 우대를 국세청 명단으로 자동 적용한다고 안내한다. 구체적인 우대 요율은 적혀 있지 않다 [7]
- [사실] KG이니시스는 여신전문금융업법에 따라 영세·중소 사업자가 우대 수수료를 받을 수 있다고 안내한다. 구체적인 요율은 적혀 있지 않다 [8]
- [사실] 두 곳 모두 정기결제(빌링) 전용 요율은 공개 페이지에 없다 [7][8]
- [사실] NHN KCP는 홈페이지·서비스 페이지에 자동결제(빌링키) 서비스 설명만 있고 공개 수수료표는 없다 [9]
- [해석] 비교 기준은 공개 요율표와 가입비가 모두 나온 토스페이먼츠로 잡았다. 실제 계약 전에 정기결제 요율과 영세 우대 여부를 상담으로 확인한다

### 4. 구독제 vs 건당 요금

| 방식 | 장점 | 단점 |
|---|---|---|
| 순수 구독 | 매달 수익이 들어와 고정비를 맞추기 쉬움 | [해석] 기획을 몇 달에 한 번 하는 작은 브랜드는 쓸 때만 가입하고 해지하기 쉬움 |
| 순수 건당 요금 | 가끔 쓰는 사용자도 부담 없이 결제 | [해석] 매달 들어오는 수익이 없어 고정비를 맞추기 어려움 |
| **구독 + 건당 (추천)** | 자주 쓰는 브랜드는 구독, 가끔 쓰는 브랜드는 건당 | 상품이 2개라 설명이 조금 복잡함 |

### 5. 추천 요금표

| 상품 | 가격 (안) | 1건·1명당 이익 | 고정비를 넘기는 기준 |
|---|---|---|---|
| 무료 체험 | 기획서 1건 (검수 포함) | – | 가입 유도용 |
| 건당 이용권 | ₩14,900 / 1건 (수정 5회 포함) | 약 ₩12,300 | 월 7건 |
| 월 구독 | ₩29,000 / 월, 5건 포함, 초과분 건당 ₩4,900, 남은 건수 이월 없음 | 구독 1명당 약 ₩17,900 | **구독자 5명** |

- 이익 계산: 판매가 − API 비용(₩2,000 × 건수) − 결제 수수료(3.74%)
  - 건당 이용권: 14,900 − 2,000 − 557 ≈ ₩12,300 → 75,000 ÷ 12,300 ≈ 6.1 → **월 7건**
  - 월 구독: 29,000 − 10,000 − 1,085 ≈ ₩17,900 → 75,000 ÷ 17,900 ≈ 4.2 → **구독자 5명**
  - 초과 1건(₩4,900): 4,900 − 2,000 − 183 ≈ ₩2,700
- 처음 시작하는 달에는 PG 가입비 22만 원이 따로 든다 [7]
- [해석] 월 구독 ₩29,000은 매니패스트 Pro($20 ≈ ₩29,000)와 같은 가격이다 [1]. "같은 가격인데 뷰티 전용 기획서와 광고 표현 검수까지 해 준다"는 비교를 할 수 있다

### 6. 단가는 낮고 수익은 큰 요금

| 상품 | 고객이 보는 1건 단가 | 결제 1번당 이익 | 이익률 |
|---|---|---|---|
| 건당 이용권 | ₩14,900 | 약 ₩12,300 | 약 83% |
| **월 구독 (5건)** | **₩5,800** | **약 ₩17,900** | 약 62% |
| 구독 초과분 | ₩4,900 | 약 ₩2,700 | 약 55% |

- [해석] 월 구독은 1건 단가가 건당 이용권의 약 40%라 고객에게 가장 싸 보이고, 우리에게는 결제 1번당 이익이 가장 크다. 대표 상품으로 내세운다
- [해석] 위 이익은 5건을 모두 쓴다고 가정한 값이다. 남은 건수는 이월되지 않으므로 고객이 덜 쓰면 이익이 더 커진다
- [해석] 초과분 ₩4,900은 단가가 가장 싸지만 이익이 작다. 홍보에 앞세우지 않고 "더 필요하면 추가"용으로만 둔다
- [아이디어] 연간 구독 (예: ₩290,000, 2개월 무료, 월 환산 약 ₩24,200)
  - 1건 단가가 약 ₩4,800까지 내려간다
  - 결제가 1년에 한 번이라 해지가 줄고 매출이 미리 들어온다
  - 월 이익은 약 ₩13,300으로 줄어든다 (24,200 − 10,000 − 결제 수수료 약 905). 아직 검토 전인 수치다

### 7. 홍보·마케팅 제안

**핵심 메시지**

| 메시지 | 근거 | 쓸 때 지킬 것 |
|---|---|---|
| "뷰티 신제품 기획서, 1건 ₩5,800" | 월 구독 ₩29,000 ÷ 5건 | [아이디어] 크몽·숨고 기획서 외주 가격과 비교해 보여 준다. 외주 가격은 아직 조사 안 함 |
| "같은 값이면 뷰티 전용" | 매니패스트 Pro 월 $20과 같은 가격 [1] | 비교 문구에는 날짜와 근거를 붙인다 (예: "2026년 11월 기준 매니패스트 Pro 월 $20"). 확인하지 않은 "더 싸다·더 빠르다"는 쓰지 않는다 |
| "기획서부터 광고 표현 검수, OEM 문의까지" | `beautyagent/positioning/positioning_map.md` 맵 2의 실행 연결 | 아직 만들지 않은 기능은 "출시 예정"으로 표시한다 |

**고객을 데려오는 방법**

| 방법 | 내용 | 비용 |
|---|---|---|
| 무료 광고 표현 검수기 | [아이디어] 화장품 문구를 넣으면 금지 표현을 짚어 주는 작은 무료 도구. 검수만 쓰러 온 사람에게 기획서 무료 체험 1건을 권한다 | 낮음 (Haiku 5.5 사용, API 비용 거의 0 [4]) |
| 샘플 기획서 공개 | [아이디어] 팀이 조사한 한방 원료로 만든 기획서 1~2건을 공개해 결과물을 먼저 보여 준다 | 거의 없음 |
| 지역 기관과 설명회 | [아이디어] 경산 화장품특화단지, 대구·경북 화장품 지원기관, 학교 창업지원단과 설명회·워크숍을 열고 참가자에게 무료 체험을 준다 | 낮음 |
| 뷰티 창업 커뮤니티 | [아이디어] 화장품 창업·OEM 커뮤니티에 기획 팁 글을 올리고 무료 체험 링크를 붙인다 | 거의 없음 |
| 첫 고객 할인 | [아이디어] 첫 구독 고객 10~20곳에 3개월 할인을 주고 후기·인터뷰를 받는다 | 할인만큼 |

**다른 조사와 엮기**
- [아이디어] 지역 기관 설명회를 아래 "아직 모르는 것"의 고객 조사 자리로 같이 쓴다. 한 해 기획 건수, 낼 의향이 있는 금액을 직접 묻는다
- [아이디어] 설명회 참가자에게 Van Westendorp 가격 질문 4개를 받아 ₩29,000이 맞는 가격인지 검증한다

**홍보할 때 지킬 것**
- [해석] 샘플 기획서와 검수기 예시에 나오는 제품 문구도 팀 광고 표현 규칙(`research/LJH_K6_광고표현규칙.md`)을 지킨다. "치료", "염증 완화" 같은 의약품식 표현은 쓰지 않는다. 광고 표현 검수를 파는 서비스라 우리 홍보물부터 규칙에 맞아야 한다
- [해석] "기획 시간 90% 단축" 같은 숫자는 직접 측정하기 전에는 쓰지 않는다. 매니패스트도 이런 숫자는 고객 후기로만 싣는다 [1]

### 8. 주의할 점
- [해석] 위 손익분기점은 인프라·결제 고정비만 넣은 숫자다. 인건비가 빠져 있으므로 발표에서는 "인프라 기준 손익분기점"이라고 밝힌다
- [해석] 건당 이익은 API 비용을 건당 ₩2,000 안으로 묶을 때만 남는다. 건당 수정 횟수와 모델별 사용량에 한도를 둔다
- [해석] 환율이 오르면 달러로 내는 고정비와 API 비용이 같이 오른다
- [해석] 팀원 3명이 모두 Vercel 개발자 좌석을 쓰면 Vercel 비용이 월 $60가 되어 고정비가 월 약 ₩133,000으로 늘어난다 [6][7]. 이때 손익분기점은 구독자 8명 또는 건당 이용권 월 11건이다. 배포 담당 1명만 개발자 좌석을 쓰고 나머지는 무료 보기 좌석을 쓰면 비용을 줄일 수 있다
- [사실] Hobby 플랜이나 Pro 체험 중에는 Vercel이 올린 콘텐츠를 AI 학습에 쓸 수 있다고 약관에 적혀 있다 [5]. 고객 기획 데이터를 다루므로 이 점에서도 유료 Pro가 맞다
- [해석] 영세·중소 우대 수수료를 받으면 결제 수수료가 내려가 손익분기점도 조금 낮아진다 [7][8]
