# 🌿 대구 한방 뷰티 에이전트 – 팀 조사 규칙
 
> 대구 약전골목에서 출발한 한방 뷰티 브랜드의 AI 에이전트를 만들기 위한 자료조사 공간이에요.
> 여기 쌓인 조사는 나중에 **에이전트가 읽는 지식 파일**이 돼요. 그래서 모두 **같은 양식, 확실한 출처**로 써요.
 
---
 
## 0. 📁 이 저장소의 파일
 
| 파일 | 역할 | 할 일 |

## 2. 🌳 브랜치
 
```
main      ← 제출용 최종본 (마일스톤 때만 업데이트)
  ↑
research  ← 팀 공용 노트 (리뷰 받은 조사가 모이는 곳)
  ↑       ↑       ↑
 HSJ     LJH     MEJ   ← 각자 연습장
```
 
- **내 브랜치**에서만 작업해요. `research`, `main`에 직접 push ❌
- 최신 조사는 **research**에 있어요. 그래서 작업 전에는 main이 아니라 research를 받아와요.
- 브랜치 이름은 **소문자** `research`예요.
---
 
## 3. 🔁 작업 순서
 
```bash
# ① 시작 전: 내 브랜치로 이동 + 최신 조사 받기
git switch LJH                # 자기 브랜치 이름으로
git pull origin research
 
# ② research/_template.md 복사 → research/LJH_당귀-산지.md 로 저장 → 조사 작성
 
# ③ 저장하고 올리기
git add .
git commit -m "[LJH] 당귀 산지 조사 추가"
git push origin LJH
```
 
**④ GitHub에서 PR 보내기**
- **"Compare & pull request"** 클릭
- **base: `research`** ← compare: `내 브랜치` 확인
- Reviewers에 다음 사람 지정 → 리뷰 순서: **HSJ → LJH → MEJ → HSJ**
- 1명이 승인하면 Merge

## 4. 📝 조사 파일 쓰는 법
 
모든 조사는 `research/_template.md`를 복사해서 써요.
- 파일 이름: `내이름_주제.md` (예: `MEJ_경쟁브랜드-설화수.md`)
- 양식 순서: 기본 정보 → 한 줄 요약 → 핵심 내용 → 상세 조사 → 에이전트 활용 → 광고 표현 체크 → 다른 팀원에게 → 아직 모르는 것 → 출처
**사실과 생각을 구분해요.** 에이전트가 우리 아이디어를 사실로 착각하지 않게요.
 
| 태그 | 뜻 | 예시 |
|---|---|---|
| `[사실]` | 출처로 확인된 것 | [사실] 대구약령시는 조선 효종 때 개설됐다 [1] |
| `[해석]` | 내가 분석한 것 | [해석] MZ는 레트로 감성으로 약전골목을 찾는다 |
| `[아이디어]` | 브랜드에 쓸 발상 | [아이디어] 약저울 모양 패키지 |

## 5. 🔍 출처 규칙
 
1. **출처 없는 내용은 올리지 않아요.** 문장 끝에 `[1]` 번호를 달고 아래 출처 표에 적어요.
2. **등급을 붙여요.**
   | 등급 | 자료 | 예시 |
   |---|---|---|
   | 🟢 | 정부·기관·박물관·논문·국가 DB | 대구시, 식약처, 한의약진흥원, 약령시한의약박물관, KCI·RISS |
   | 🟡 | 기사·기업 공식 자료·책·인터뷰 | 지역 신문, 브랜드 홈페이지 |
   | 🔴 | 블로그·SNS·유튜브·나무위키·AI 답변 | 참고만! 🟢🟡로 다시 확인 |
3. **중요한 사실은 2곳 이상**에서 확인해요 (연도, 인물, 제도명, 약재 효능). 출처끼리 다르면 `❗충돌` 표시.
4. **확인일**(내가 본 날)과 논문·보고서는 **쪽수**까지 적어요.
5. **복사 말고 요약.** 인용은 짧게 따옴표로만.
6. **이미지**는 사용 가능 여부를 표시해요: ✅ 직접 촬영·공공누리 1유형 / ⚠️ 출처표시 필요 / ❌ 참고용만
> 자료 종류별 출처 형식은 `_template.md`, AI로 정리할 때는 `prompts/source-grading-prompt.md`를 보세요.
