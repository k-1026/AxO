### 4-2. 서브에이전트 A~D 실행
```

A 사업 모델: 누구에게·무엇을·어떻게 전달·무엇으로·파트너 → parts/A_bm.md
```

## 5단계 · 과제 — 원페이지 취합 · 사실 검증 · 이슈 3개 (Claude Code)

### 5-1. parts 보완
`check.md` 지적을 반영해 태그 없는 문장에 [출처 n] · [I] · [U]를 붙이고 다시 커밋해요.

### 5-2. 취합 → onepager.md
```
실습/company/아모레퍼시픽/parts/ 4개를 교안 원페이지 템플릿 8칸 순서
(1 기업 개요 · 2 사업 모델 6질문 · 3 주요 제품·서비스 · 4 최근 동향 3건 · 5 산업 지형 내 위치 ·
6 글로벌 확장 경로 · 7 우리 자산과의 접점 · 8 출처·충돌·미확인)로 합쳐
onepager.md 초안을 만들어 줘. A와 B가 다르게 말하는 항목은 충돌 표로 8번 칸에 넣고,
경쟁사 비교는 같은 칸끼리 표로. 7번 '우리 자산과의 접점' 칸은 비워 둬.
밸류체인 단계 이름(IP → 콘텐츠 → 캠페인 → 커머스 기획전 → 구매)을 2번 칸에 경로로 표시해 줘.
```
> 7번 칸은 교안 규칙상 **팀이 직접** 써요 (Top 자산·페르소나가 어느 상품·채널과 만나는지, 2줄 이상).

### 5-3. 사람 검증 → verify.md
```
onepager.md 의 문장 중 [출처 n] 이 붙은 것을 골라, sources/ 의 해당 파일에서 근거 문장을 그대로
인용하고 줄 번호를 표로 만들어 줘. 근거를 못 찾은 문장은 [U] 로 바꿔 verify.md 에 목록화해 줘.
```
