# Local 결과 패키지 — AxO 팀 (뷰티 트랙)

⚠️ 예시 초안이에요. 저장소 루트 `README.md`(팀 규칙)는 그대로 두고, 결과 패키지용으로 따로 만든 파일이에요. 팀이 확정하면 문구를 바꿔서 써요.

- **팀 자산 Top 3:** ① 대구약령시 약전골목 (1658년 무렵 개설, 지금까지 운영되는 유일한 조선시대 약령시) ② 대구약령시한의약박물관·한방의료체험타운 (한방뷰티·족욕 등 체험 공간) ③ 대구약령시 한방문화축제 (매년 5월, 2026년 방문객 11만여 명)
- **핵심 메시지:** "오래된 약재의 지혜를 오늘의 피부 습관으로."
- **페르소나:** 20~30대 — 한방은 '어르신 화장품'이라 망설이지만 향·사용감·가격이 맞으면 고르고, 나와 비슷한 사람의 후기를 믿는 사람
- **스토리보드 행동유도:** 진단·저장 → 체험(약전골목 팝업) → 구매(계절 기초라인) → 재구매(계절 교체)

## 🔗 행동유도가 이어지는 산업 · 상품 · 서비스

| 단계 | 고객 행동 | 이어지는 산업 | 실제 상품·서비스 | 연결 후보 기업·장소 |
|---|---|---|---|---|
| 1. 진단·저장 | 에이전트에서 피부 고민·계절을 고르고 추천 결과를 저장 | 뷰티 테크 (AI 추천) | 피부타입 → 기초라인 추천 에이전트, 결과 화면 저장·공유 | 우리 에이전트 (K9 결과화면 시안) |
| 2. 체험 | 약전골목 팝업에서 약재 향을 맡고 샘플 사용 | 관광·체험 서비스 | 한방뷰티 체험(피부 측정 → 스킨케어), 한방 족욕, 축제 부스 | 한방의료체험타운 5층, 한의약박물관, 5월 한방문화축제 |
| 3. 구매 | 계절에 맞는 약재 기초라인(토너·세럼·크림) 구매 | 화장품 제조·유통 | 중저가 한방 기초 스킨케어 (예: ONLEAF / OMIZA / HYDRATE / SERUM) | 제조: 코스맥스 등 ODM / 유통: 올리브영·자사몰 |
| 4. 재구매 | 계절이 바뀌면 다음 약재 라인으로 교체 | 화장품 유통·구독 | 24절기·4계절 시즌 기획전, 리필·정기배송 | 자사몰, 올리브영 기획전 |
| 5. 확장 | 해외 고객이 'K-한방 루틴'으로 구매 | 화장품 수출 | 해외 역직구·B2B 유통 | 실리콘투(유럽·북미·중동) |
