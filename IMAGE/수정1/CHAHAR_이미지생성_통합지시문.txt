기준 폴더: IMAGE/수정1

1. 이 파일의 역할과 현재 상태

이 파일은 IMAGE/CHAHAR_수정지시서.txt와 IMAGE/CHAHAR_이미지수정_요청문.json을 대체하는 최신 이미지 생성 지시문이다. 이후 이미지를 수정할 때는 이 파일과 같은 폴더의 선택 이미지를 기준으로 한다. 과거 지시와 충돌하면 이 파일의 최종 기준을 우선하고, 이후 사용자의 직접 수정 요청이 있으면 그 요청을 우선한다.

현재 폴더는 사용자가 지정한 조합이다. 토너는 초안5에서, 나머지는 초안4에서 가져왔으며 이미지를 다시 생성하거나 변형하지 않고 그대로 복사했다. 6종 제품이지만 미스트 캡 2안을 포함하므로 이미지 파일은 7장이다. 이 선택은 다음 작업의 기준 이미지 선정이며, 모든 제품의 실측 치수나 실제 수용량 검증을 뜻하지 않는다.

사용자가 최종 지정한 목표 용량:
- 토너 200mL
- 세럼 50mL
- 크림 50mL
- 미스트 250mL: 둥근 캡과 네모 캡은 같은 제품의 캡 대안이다.
- 펌프형 로션 80mL
- 튜브형 로션 120mL

목표 용량 지정 후 토너의 단지형 캡 수정본만 생성됐다. 세럼·크림의 후속 생성은 도구의 사용 한도로 실패했고, 미스트·로션의 용량 반영 수정과 동일 축척 비교 이미지는 생성되지 않았다. 따라서 초안4에서 가져온 6장은 목표 용량을 반영한 재생성 완료본으로 표시하지 않는다. 토너도 200mL를 디자인 목표로 입력한 시안이며 실제 수용량을 측정한 결과는 아니다. 현재 사용자 요청은 이미지 정리와 지시문 통합이므로 이 단계에서 추가 이미지는 생성하지 않았다.

3. 모든 제품의 공통 생성 기준

- 내장 이미지 생성 도구의 편집 기능으로 기존 이미지를 수정한다. 편집 전 원본을 직접 확인하고 제품별 참조 이미지의 역할을 구분한다.
- 한국 한방 단지에서 따온 매끈한 현대적 곡면을 유지한다. 20~30대 대상의 밝고 눈에 띄는 체리 레드·핑크 오미자 라인 예시다.
- 용기는 내용물이 채워진 상태로 표현한다. 색과 제형은 디자인 시각화이며 실제 성분·배합·효능을 의미하지 않는다.
- 제품 위의 글자는 기존 얇은 원형 마크 안의 대문자 CHAHAR만 유지한다. 제품 유형·용량·효능·홍보 문구를 추가하지 않는다.
- 밝은 핑크와 흰색 스튜디오 배경, 왼쪽 전체 제품 컷과 오른쪽 동일 제품의 상세 컷 구성을 유지한다.
- 뚜껑·받침의 세로 홈, 골, 장식 줄, 금속 띠를 만들지 않는다. 자연스러운 접합선과 기능상 필요한 힌지는 허용한다.
- 세럼·미스트·펌프형 로션은 어깨 곡선, 둥근 받침과 단지형 캡 받침이 한 제품군으로 보이도록 맞춘다. 용량에 따른 몸체 크기 차이는 유지한다.
- 펌프·스포이드·힌지·밀봉 돌기·토출구는 서로 맞물리는 구조로 표현한다. 캡 안팎을 혼동하지 않는다.
- 사용자가 한 부분만 수정하라고 하면 그 부분만 편집한다. 몸체 비율·로고·색·구도·조명을 함께 바꾸지 않는다.
- 기존 이미지를 덮어쓰지 말고 다음 버전 폴더에 저장한다. 사용자가 교체를 명시한 경우에만 원본을 대체한다.

4. 제품별 최종 이미지 생성 지시문

실행 방법: 공통 기준을 적용하고 아래 해당 제품의 지시문을 함께 사용한다. 편집 대상은 이 폴더의 해당 PNG다. 아누아 사진은 세럼 누름부의 비율 확인이 필요할 때만 보조 참조한다.

4-1. 토너 200mL

편집 대상: CHAHAR_토너_200ml.png
비율 확인용 원형: IMAGE/초안1/CHAHAR_토너.png

토너의 목표 용량은 200mL다. 몸체의 가로세로 비율, 어깨와 아래 받침의 곡선은 초안1 토너를 유지한다. 현재 선택 이미지의 매끈한 체리 레드 단지형 플립 캡을 유지한다. 캡은 볼록한 배, 살짝 들어간 아래 받침과 둥근 곡면을 가지며 실제로 열고 닫히는 힌지형이다. 펌프형으로 바꾸지 않는다. 투명한 용기 안의 맑은 핑크 액상, CHAHAR 원형 마크를 보존한다. 왼쪽은 캡을 닫은 전체 제품, 오른쪽은 동일한 단지형 캡을 연 상세 컷으로 만든다. 오른쪽에는 기본 원형 토출구와 대응하는 밀봉 돌기를 표현한다. 몸체 비율을 바꾸지 않는 범위에서 200mL 목표를 검토한다.

4-2. 세럼 50mL

편집 대상: CHAHAR_세럼.png
보조 참조: IMAGE/CHAHAR_스포이드_비율참고.png

세럼의 목표 용량은 50mL다. 현재 선택 이미지의 둥근 세로형 고무 누름부 비율을 그대로 유지하고 연한 핑크색을 유지한다. 흰색으로 바꾸거나 납작하게 또는 뾰족하게 변형하지 않는다. 고무 누름부 아래 체리 레드 단지형 받침, 투명한 핑크 세럼 몸체, 스포이드 관과 기존 CHAHAR 마크를 유지한다. 아누아 참고 사진은 고무 부분의 형태와 높이 대 너비 비율 확인에만 사용하며 브랜드·광고·골이 있는 캡은 복제하지 않는다. 50mL의 아담한 몸체로 크기 관계를 검토하되 누름부의 종횡비는 바꾸지 않는다. 왼쪽 전체 컷과 오른쪽 확대 컷의 스포이드 구조를 일치시킨다.

이전 단계의 몸체 가로 90%, 세로 107%는 당시 원형 대비 수정 목표였으며 현재 선택 이미지에 다시 누적 적용하지 않는다. 고무 누름부 높이 대 너비 약 1.27은 직전 편집에 사용한 시각적 목표이고 실측 제작 규격은 아니다. 재편집 시에는 현재 이미지의 비율 자체를 우선한다.

4-3. 크림 50mL

편집 대상: CHAHAR_크림.png

크림의 목표 용량은 50mL다. 용기 몸체는 완전히 불투명한 밀키 핑크로 유지한다. 닫힌 용기 벽을 통해 내용물이나 캡슐이 비치면 안 된다. 매끈한 체리 레드 뚜껑, 살짝 길어진 뚜껑 옆면, 조금 높아진 둥근 아래 받침, 흰색 CHAHAR 마크를 유지한다. 홈·장식 줄·금속 띠를 추가하지 않는다. 왼쪽 전체 컷은 닫힌 단지다. 오른쪽은 같은 단지를 열고 뚜껑을 옆에 놓아 연핑크 젤크림과 작은 진주빛 흰색·핑크 캡슐을 위쪽 열린 입구에서만 보여 준다. 캡슐은 자연스럽게 흩어지며 거대한 구슬·씨앗·기포처럼 표현하지 않는다. 50mL의 손바닥 크기 단지로 비례 관계를 검토한다.

4-4. 미스트 250mL 둥근 캡

편집 대상: CHAHAR_미스트_둥근캡_닫힘.png
원형 참조: IMAGE/초안1/CHAHAR_미스트.png

미스트의 목표 용량은 250mL다. 길고 둥근 투명 용기, 맑은 핑크 액상, 액면과 내부 관, 어깨와 아래 받침, 체리 레드 단지형 받침을 유지한다. 둥근 투명 보호 캡은 맨 위의 가늘고 긴 분사 펌프만 감싸고 닫힌다. 캡의 아래 가장자리는 빨간 단지형 받침의 윗면에서 끝난다. 빨간 단지형 받침 전체는 캡 밖 아래에 노출되어야 하며 투명 캡이 받침의 옆면까지 내려오면 안 된다. 캡은 펌프보다 약간 넓고 단지형 받침보다 확실히 좁다. 수직 원통 옆면과 둥근 돔 윗면을 사용한다. 왼쪽 전체 컷과 오른쪽 확대 컷 모두 동일하게 닫힌 구조로 표현한다. 옆에 별도의 느슨한 캡은 두지 않는다. 토너 200mL보다 많은 250mL를 담는 긴 몸체의 크기 관계를 검토한다.

4-5. 미스트 250mL 네모 캡

편집 대상: CHAHAR_미스트_네모캡_닫힘.png
둥근 캡 버전과 몸체·제형·용량·분사 펌프·빨간 단지 받침은 같게 유지한다. 캡 형상만 정사각 단면의 좁은 투명 직육면체로 만든다. 윗면은 평평하고 옆면은 곧은 평면이며 모서리는 아주 조금만 부드럽게 처리한다. 이 캡도 분사 펌프만 덮는다. 캡 하단은 단지 받침의 윗면에서 끝나며 단지는 캡 밖에 완전히 노출된다. 왼쪽 전체 컷과 오른쪽 확대 컷의 구조를 일치시킨다. 둥근 캡 이미지를 대체하지 말고 별도 이미지로 저장한다.

4-6. 펌프형 로션 80mL

편집 대상: CHAHAR_로션_펌프형.png

펌프형 로션의 목표 용량은 80mL다. 아담한 둥근 몸체와 완전히 불투명한 밀키 핑크 소재를 유지한다. 내부 관이나 액면·내용물이 몸체 벽을 통해 보이면 안 된다. 체리 레드의 가늘고 실용적인 펌프, 부드러운 단지형 펌프 받침, 둥근 어깨와 약간 올라온 아래 받침, 기존 CHAHAR 마크를 유지한다. 오른쪽 확대 컷은 동일한 펌프의 작은 출구에 아주 작은 밀키 핑크 로션 방울만 보인다. 80mL 용량 목표에 맞춰 세럼 50mL보다 몸체 수용량이 크고 토너 200mL보다 작은 크기 관계를 검토한다. 크림이나 튜브형에 있는 캡슐을 이 제품에 임의로 추가하지 않는다.

4-7. 튜브형 로션 120mL

편집 대상: CHAHAR_로션_튜브형.png
제형 참조: CHAHAR_크림.png의 열린 단지 안 내용물

튜브형 로션의 목표 용량은 120mL다. 짧고 통통한 반투명 프로스트 핑크 연질 튜브, 윗면의 납작한 봉합선, 기존 CHAHAR 마크를 유지한다. 내용물은 크림과 같은 연핑크 캡슐 젤크림으로 채우되, 캡슐은 크림보다 확실히 작게 만든다. 동일한 실제 축척에서 크림 캡슐 지름의 약 40%를 시각적 목표로 삼되 실제 성분·입자 규격을 주장하지 않는다. 반투명 몸체를 통해 작은 캡슐이 부드럽게 보이게 한다.

하단 캡의 바깥 실루엣은 매끈한 체리 레드 단지형으로 유지한다. 단, 뚜껑을 열었을 때 내부 토출구는 평평한 원형 면 위의 짧고 단순한 원통형 구멍인 기본형이다. 토출구를 작은 단지·볼록한 배·오목한 목·장식 입구로 만들지 않는다. 열린 덮개에는 토출구와 대응하는 작은 막힌 밀봉 돌기가 있어야 한다. 오른쪽 확대 컷에 동일한 캡슐 젤크림 방울을 작게 표현한다. 120mL 목표는 몸체 폭과 깊이도 고려해 검토하되 짧고 통통한 인상을 유지한다.

5. 용량을 반영하는 후속 작업

위 용량은 사용자 지정 목표다. 기존 시안의 픽셀을 mL로 환산한 값이나 실제 용기 제조사의 규격이 아니다. 앞서 별도 기획안에서 찾은 토너 200mL·세럼 50mL·크림 50mL 예시는 과거 이미지 생성의 입력 기준이 아니었다. 이제부터는 사용자가 직접 지정한 6종 용량을 기준으로 한다.

이미지만으로 실제 수용량을 측정하거나 보증하지 않는다. 실제 수용량을 맞추려면 용기 내부 치수·벽 두께·바닥 두께·충전 여유 공간과 펌프 또는 스포이드가 차지하는 부피를 확인해야 한다. 외형이 커 보인다는 이유만으로 목표 용량 반영 완료라고 표시하지 않는다.

후속 이미지는 제품별 기존 형상과 재질을 보존하면서 용량에 맞는 몸체 크기 관계를 검토한다. 액면만 올리거나 카메라 확대·축소만으로 용량을 바꿨다고 처리하지 않는다. 미스트가 토너보다 25% 더 많은 용량이라고 해서 선형 치수를 25% 늘리는 방식도 사용하지 않는다.

현재 승인된 실측 외형 치수는 없다. 초안5 대기 프롬프트의 mm 치수와 화면상 px 높이는 당시 AI가 세운 비교용 가정이며 사용자가 지정한 제작 규격이 아니다. 해당 숫자를 승인된 규격으로 승계하거나 정밀 수용량 근거로 삼지 않는다. 향후 실제 치수를 정하면 그 치수를 별도 기록하고 이 지시문을 갱신한다.

동일 축척 비교 컷이 필요하면 6종을 같은 바닥선·카메라 거리·축척으로 나란히 표현한다. 미스트 둥근 캡과 네모 캡은 동일 몸체의 두 대안이므로 별도 비교 컷 또는 추가 컷으로 제시한다. 제품별 확대 크기가 다른 개별 상세 컷을 실제 크기 비교 자료로 사용하지 않는다. 이 비교 컷은 이전 작업에서 제안됐지만 아직 생성되지 않았다. 제품 표면에는 CHAHAR만 유지하며 별도 용량 설명은 사용자가 요청한 경우 이미지 바깥 설명 또는 별도 비교 자료에 둔다.

6. 실제 이미지 생성과 수정 과정

초안1 보관 단계
- 2026-11-12 안내 파일 기준 토너·세럼·크림·미스트·펌프형 로션·튜브형 로션의 기존 시안 6종 보관.
- 토너는 당시 v3, 나머지는 당시 v4로 안내돼 있었다.
- 반투명 캡슐 크림, 스포이드 비율, 세럼 몸체 가로 90%·세로 107% 등의 후속 수정은 당시 미반영 상태였다.

초안2
- 기존 수정지시서·JSON·아누아 비율 사진과 초안1을 읽고 내장 이미지 편집 도구로 제품별 수정.
- 세럼: 고무 누름부를 둥근 세로형으로, 몸체를 더 좁고 길게 조정.
- 크림: 당시 지시에 따라 반투명 용기와 작은 캡슐을 표현. 뚜껑 홈·금속 띠를 제거하고 뚜껑 옆면·아래 받침을 조정.
- 미스트·펌프형 로션: 수정 세럼을 보조 참조해 단지 받침과 곡선의 제품군 일관성을 조정.
- 튜브형: 단지형 외부 캡과 당시 요청된 단지형 토출구를 표현. 오른쪽 토출구·밀봉 돌기의 구조를 한 번 더 수정.
- 토너는 초안1에서 그대로 복사.

초안3
- 사용자 첨부의 누름부 확대 이미지와 아누아 사진을 보고 세럼 고무 부분을 흰색으로 편집한 뒤 비율을 추가 조정. 몸체와 빨간 받침은 유지하도록 지시.
- 크림: 사용자의 변경 요청에 따라 몸체를 완전 불투명으로 변경. 열린 단지 내부의 캡슐 제형은 유지.
- 미스트: 네모 캡을 닫은 이미지를 생성했으나 빨간 단지 받침까지 캡 안에 넣는 오류가 발생. 이 구조는 최종 기준에서 폐기.
- 튜브형: 크림과 같은 캡슐 젤크림 제형을 표현하고 캡슐을 더 작게 조정.
- 이 시점에 이미지의 실제 용량은 미확정이라고 설명.

초안4
- 세럼: 사용자가 유지하라고 한 고무 부분의 비율을 보존하고 색만 원래 연핑크로 복원.
- 미스트: 단지가 캡 안에 들어간 해석 오류를 인정하고 수정. 초안1에서 둥근 캡 닫힘 버전을 만든 뒤 그 결과를 참조해 네모 캡 닫힘 버전을 별도 제작.
- 두 미스트 모두 분사 펌프만 투명 캡 안에 있고 빨간 단지는 외부에 노출.
- 튜브형: 단지형 외부 캡·작은 캡슐 제형은 유지하고 내부 토출구만 기본 원형으로 변경.
- 크림·토너·펌프형 로션은 당시 기존 이미지 유지.
- 현재 수정1에서 토너를 제외한 이미지 6장의 출처.

초안5
- 사용자: 초안1 토너 몸체 비율을 유지하면서 캡만 로션 같은 단지형으로 변경 요청.
- 사용자: 토너 200mL, 세럼 50mL, 크림 50mL, 미스트 250mL, 펌프형 로션 80mL, 튜브형 로션 120mL를 명시.
- 토너: 초안1을 편집 대상으로, 초안4 튜브형 로션을 단지형 캡 참조로 사용해 생성 완료.
- 후속 세럼·크림 생성은 HTTP 429 usage_limit_reached로 실패. 미스트 2안·로션 2종·제품군 비교 컷은 대기 요청문만 작성했고 이미지 미생성.
- 내장 도구 외의 API·CLI 방식으로 전환하지 않음.
- 현재 수정1 토너의 출처.

수정1 정리
- 사용자의 지정에 따라 초안4 토너 제외 6장과 초안5 토너 1장을 복사해 현재 기준 세트 7장 구성.
- 기존 지시문을 이 파일로 통합. 과거 지시문과 단계별 실제 프롬프트는 생성과정_원문기록.json에 보존.
- 초안1~5 원본 이미지는 유지.
- 용량별 전체 재생성은 완료로 표시하지 않고 후속 작업으로 남김.

7. 폐기되거나 뒤집힌 지시

- 크림 반투명 외벽: 최종적으로 불투명 외벽으로 변경. 캡슐은 열린 입구에서만 보임.
- 세럼 고무 흰색: 최종적으로 연핑크 복원. 마지막 고무 부분 비율은 유지.
- 미스트의 단지 받침까지 덮는 큰 캡: 폐기. 분사 펌프만 덮는 좁은 캡으로 수정.
- 튜브형 단지 모양 토출구: 폐기. 외부 단지형 캡은 유지하고 내부 토출구만 기본형으로 수정.
- 토너 v3 유지: 단지형 캡 변경 요청으로 대체. 초안1 몸체 비율은 계속 유지.
- 용량 미정: 최신 사용자 목표 용량으로 대체. 단, 과거 이미지에 그 용량이 실측 반영됐다는 의미는 아님.
- 커밋 전 확인한 원격 research의 과거 지시문에는 오미자 글자 추가와 토너 210mL 등의 별도 내용이 있었다. 이번 대화의 직접 요청과 선택 이미지에는 해당 글자가 없고 목표 용량은 200mL다. 그 원문은 이력으로 보존하되 현재 선택본을 임의로 변경하거나 최종 기준에 혼합하지 않는다.
- 과거 비율·치수 보정값을 현재 이미지에 반복 적용하지 않는다.

8. 참고 이미지와 이력 파일 사용

아누아 참고 사진: IMAGE/CHAHAR_스포이드_비율참고.png
- 사용자 제공 제3자 사진. 사용 표기 ❌ 결과물 재사용 불가, 비율 참고용.
- 고무 누름부 비율에만 참고한다. 아누아 로고, 광고 문구, 골이 있는 캡, 사진 배경·구도는 복제하지 않는다.
- 사용자가 첨부했던 확대 캡처는 편집 부위를 식별하는 보조자료였다. 특정 사용자의 임시 폴더 경로를 후속 작업의 필수 입력으로 삼지 않는다.

생성과정_원문기록.json
- 기존 수정지시서와 요청문, 초안1 안내, 초안2~5 기록에 저장된 실제 원문을 보존한다.
- 실패한 호출의 프롬프트와 아직 실행하지 않은 대기 프롬프트도 들어 있으므로 원문이 있다는 이유로 생성 완료라고 해석하지 않는다.
- 이 파일의 최종 기준과 충돌하는 과거 프롬프트는 실행하지 않는다.

이미지목록.json
- 선택 이미지의 원본 위치, 목표 용량, 생성 상태, 복사 검증용 SHA-256을 기록한다.
- 현재 결과물 추적에 사용하며 실측 수용량 인증 자료가 아니다.

9. 결과 확인 항목

- 브랜드 철자가 CHAHAR이며 다른 문구가 없는가.
- 토너 몸체가 초안1의 비율을 유지하고 단지형 캡만 바뀌었는가.
- 세럼 고무 누름부가 현재 비율을 유지한 핑크색인가.
- 크림 외벽은 완전 불투명하고 열린 단지 안에만 캡슐이 보이는가.
- 미스트 두 캡 모두 분사 펌프만 덮고 빨간 단지 받침이 노출되는가.
- 미스트 두 버전의 몸체는 동일하며 캡 형상만 다른가.
- 펌프형 로션 외벽이 완전 불투명한가.
- 튜브형의 캡슐이 크림보다 작고 내부 토출구는 기본 원형인가.
- 각 제품의 전체 컷과 상세 컷 구조가 일치하는가.
- 목표 용량과 실제 생성·검증 상태를 구분해 기록했는가.
