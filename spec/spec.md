## 1. 개요

| 항목 | 내용 | 근거 |
|---|---|---|
| 제품 | 계절 제품 개발 아이디어 에이전트 | 기획안 |
| 브랜드 | CHAHAR / 차하르 (가칭 1순위, 상표 확인 필요) | D-02 |
| 사용자 | 상품기획팀 BM 1명 (대표 페르소나: 윤소라 32세, BM 4년 차, 직원 10명 미만 대구 브랜드) | D-06 |
| 브랜드 타깃 고객 | 20~30대 | D-10 |
| 입력 | 계절 하나 (봄 / 여름 / 가을 / 겨울) | D-03 |
| 출력 | 계절별 라인 후보 풀 → 순위 → 상위 3개 카드 + 상세 카드 (HTML 결과 화면) | D-09 |
| 실행 환경 | Claude 프로젝트 (지침 + 지식 파일 K1~K9) | 기획안 |

### 1-1. 해결하는 문제

작은 브랜드 BM은 조사·원료·원가·법규를 혼자 맡는다 (MEJ 페르소나 근거). 그중 에이전트가 직접 푸는 핵심은 세 가지다.

| 핵심 문제 | 근거 | 에이전트의 답 |
|---|---|---|
| 쓸 수 있는 약재를 고르기 어렵다 | 안전기준 위반 41건 중 14건이 사용금지·제한 원료 (2021~2025.6) | K3 원료 후보표 안에서만 추천, 필수 통과 조건 |
| 광고 표현이 걸린다 | 식약처 점검 209건 중 83건 적발, 53건(64%)이 의약품 오인 | K6 셀프 체크 |
| 계절 근거로 라인을 정하기 어렵다 | BM 페인포인트 01·03 (업무 가설, 인터뷰 전) | K4 기후 수치 → 피부 목적 → 라인 |

### 1-2. 목표 지표 (검증 전)

| 기획서 보완 횟수 | 감소 | 제조사 전달 전 누락 때문에 보완한 횟수 | 기준값 확인 필요 |

### FR-3. 필수 통과 조건

후보 풀의 모든 후보를 아래 7개 조건으로 검사한다. **FAIL은 순위에서 제외, UNKNOWN은 "추가 검증 후보"로 따로 표시**한다. [필수]

| # | 조건 | 판단 근거 | 시안 예 |
|---|---|---|---|
| 1 | 기초라인 적합 | K3 | 길경 = 클렌저용 → FAIL |
| 2 | 한방 원료 근거 | K3 | 병풀 = 공정서 약재 아님 → UNKNOWN |
| 3 | 쓸 수 있는 원료 | K3 확인용 표 (안전기준 별표1·2 이름 일치 없음, 콘셉트 단계 기준) | — |
| 4 | 광고 표현 | K3 "쓸 수 있는 말", K6 | — |
| 5 | 기능성 절차 | LJH 기능성 고시 성분 대조 (미백 라인은 보고 필요, 감초 = 유용성감초추출물, 작약 = 고시 성분 따로 배합) | — |
| 6 | 중저가 가격 | K5 ml당 정가 범위 | — |
| 7 | 계절 고민 연결 | K4 기후 이슈 연결 여부 | — |

- 안전기준 별표에 이름이 없다는 것은 "사용 가능"이 아니라 "이름으로 목록에 없음"이다. 화면에는 "공급사 성적서로 확인 필요"를 표시한다.
