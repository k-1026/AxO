## 0. 검토 기준값 (출처 파일)

**가격: 중저가 ml당 정가** (`research/LJH_올리브영-상위제품-가격.md` 2장)
| 유형 | 중저가 ml당 정가 | 예: 이 용량이면 정가 범위 |
|---|---|---|
| 토너 | 36~90원 | 300ml → 약 10,800~27,000원 |
| 로션 | 98~193원 | 200ml → 약 19,600~38,600원 |
| 미스트 | 88~192원 | 150ml → 약 13,200~28,800원 |
| 크림 | 280~410원 | 50ml → 약 14,000~20,500원 |
| 세럼·앰플 | 148~430원 | 50ml → 약 7,400~21,500원 |

- 계산: 정가 ÷ 용량 = ml당 정가 → 위 범위 안이면 ✅
- 세럼 범위는 에센스 로션이 섞여 낮게 나온 값이라, 살짝 벗어나면 ❌ 대신 메모만 남겨요

**금지어: K6 셀프 체크 6문항** (`research/LJH_K6_광고표현규칙.md` H표)
1. 질병명·의학적 효능 (아토피·여드름·기미, 치료·재생·항염·면역)
2. 시술·전문가 (보톡스·필러·니들, 의사·한의사·병원·협회)
3. 일반 라인의 미백·화이트닝·주름 개선·자외선 차단, 흔적 효능 표현(없애준다·제거·개선·옅어짐). '흔적'을 제품명에 쓰면 기능성 라인인지, 명사로만 썼는지 확인 (K6 팀 결정 조건 4가지)
4. 실증 대상 (수치·기간·비교, 혈행·붓기·콜라겐·장벽 개선)에 "실증 필요" 표시가 없음
5. 원료 설명·상품명·캠페인 제목의 약재 효능, 처방·보약·기혈 순환, 심신 효능, 천연·유기농
6. 최고·최초·무자극·부작용 없음

**경쟁: 원료별 선점 정도** (`research/LJH_원료별-경쟁제품.md` 3장)
| 선점 | 원료 | 대표 경쟁 제품 |
|---|---|---|
| 강함 | 쑥, 어성초, 인삼, 병풀 | 한율 쑥판텐·쑥히알, 아누아 어성초 77·아비브, 조선미녀·설화수, 스킨1004·브링그린 |
| 보통 | 감초 | 잇츠스킨 감초줄렌 |
| 스킨케어로는 약함 | 홍삼, 오미자 | 랩1899 (홍삼), 파넬 워시오프 (오미자) |
| 약함 | 당귀, 황기, 작약 | 작약만 구달 피오니 앰플 1개 |
- 선점 강함 원료를 고르면 차별화 이유("한방 브랜드 + 중저가" 등)가 있어야 C2 ✅
