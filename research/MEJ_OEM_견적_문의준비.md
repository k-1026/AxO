### 2. 문의할 때 꼭 물어볼 항목
견적은 아래 조건이 정해져야 비교할 수 있어요. 업체마다 같은 조건으로 물어보세요.

| 구분 | 물어볼 것 | 왜 필요한가 |
|---|---|---|
| 가능 여부 | 다른 회사 제품을 대신 만들어 주는지(OEM), 처방까지 개발해 주는지(ODM) | 공장등록 목록에는 안 나와요 |
| 최소 주문 수량 | 제품당 최소 몇 개부터 만드는지 (MOQ) | 첫 출시 수량 결정 |
| 단가 | 개당 제조 단가 (내용물만 / 용기·포장 포함 각각) | 출시가 계산 |
| 원료 | 우리가 정한 한방 추출물(예: 오미자·작약)을 쓸 수 있는지, 원료를 우리가 공급해도 되는지 | 원료 후보표와 연결 |
| 처방 개발비 | 처방 개발·샘플 비용, 샘플 몇 번까지 무료인지 | 초기 비용 |
| 기간 | 샘플까지, 본생산까지 걸리는 기간 | 절기 출시 일정 |
| 기능성 | 기능성화장품 심사·보고를 대행해 주는지, 비용·기간 | 기능성 라인 |
| 시험 | 안정성·자극 시험을 해 주는지, 비용 | 품질·광고 실증 |
| 서류 | 원료 성적서(CoA), 전성분표 제공 여부 | 배합 제한 확인 |

- 제품: 토너 300ml, 크림 50ml (기초화장품)

3. 처방 개발비와 샘플 제작 기간
4. 기능성화장품 심사·보고 대행 가능 여부

바쁘신 중에 읽어 주셔서 감사합니다.
