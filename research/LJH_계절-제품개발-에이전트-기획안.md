# 계절 제품 개발 아이디어 에이전트 기획안

Oct 30, 2026 작성 · Nov 4, 2026 전면 수정 · @이진하
(이전 이름: 계절·절기 한방 뷰티 시즌 캠페인 에이전트)

## 한 줄 컨셉

**우리가 만든 가상 한방 화장품 브랜드의 상품기획팀 직원이 "봄 시즌 무슨 제품 낼까?"라는 생각으로 4계절 중 하나를 고르면, 계절 기후에서 피부 고민을 뽑고, 스킨케어 라인 후보 2~3개(라인별 구성·약재·가격·디자인 방향)를 제안한 뒤, 출시 우선순위를 추천하는 제품 개발 아이디어 에이전트.**

- **브랜드:** 우리 팀이 만드는 가상 한방 스킨케어 브랜드 (브랜드명은 K1에서 확정, 지금 후보는 온리프·약결·허비트)
- **사용자:** 상품기획팀 **BM(브랜드 매니저)**이 결과를 확인해요
- **입력:** 계절 하나를 고름 (봄 / 여름 / 가을 / 겨울)
- **결과:** 스킨케어 라인 후보 **3개** (조건에 맞는 후보가 3개가 안 되면 **2개**) + 출시 추천 순위

## 에이전트 흐름

```
[입력] 4계절 중 하나 선택 (봄 / 여름 / 가을 / 겨울)
   │   사용자 생각: "봄 시즌 무슨 제품 낼까?"
   │
① 계절 → 기후 이슈 → 피부 고민 후보군 (여러 개)
   │   예: 봄 = 황사·미세먼지, 큰 일교차(환절기), 자외선 증가
   │       → 외부 자극 예민함 / 당김·속건조 / 칙칙함
   │   근거: K4 계절 기후·피부 이슈 표 (팀이 미리 만든 표만 씀)
   │
② 피부 고민 → 라인 + 약재 추천 (라인 3개, 안 되면 2개)
   │   예: "보습이 가장 큰 고민" → 기능성 보습·장벽 라인 + 맞는 약재 자동 추천
   │   2개로 줄이는 경우: 아래 조건을 지키는 후보가 3개가 안 될 때. 억지로 3개를 채우지 않고 이유를 한 줄 씀
   │     - 라인끼리 피부 목적이 겹치지 않을 것
   │     - 약재가 K3 원료 후보표에 있고 배합 제한에 걸리지 않을 것
   │     - 선점 '강함' 원료는 차별화 이유가 있을 것
   │   라인 종류: K2 13개 피부 목적 중에서, 기능성 여부(✅/△/❌) 표시
   │   약재: K3 원료 후보표 안에서만. 필터 = 목적 키워드 → 향 세기 → 배합 제한 → 경쟁사 선점
   │
③ 라인 구성 (라인마다 다름)
   │   예: 진정 = 토너 + 젤 크림 / 장벽 = 클렌저 + 토너 + 크림 / 보습 = 토너 + 세럼 + 크림
   │   근거: K2 구성 틀 (● 1차 출시, ○ 2차 확장)
   │
④ 출시가 제안 (제품마다 용량 + 가격)
   │   원가 쪽: 원료비 + 용기·포장 + 제조비 → 원가 ÷ 목표 원가율 = 원가 기준 출시가 (K7)
   │   시장 쪽: 용량 × 중저가 ml당 정가 범위 = 시장 기준 출시가 (K5)
   │   → 두 값을 비교해 최종 출시가 제안. 원가 자료가 없으면 시장 기준만 쓰고 "원가 확인 필요"
   │
⑤ 디자인 + 실사 제품 이미지 (라인마다)
   │   약재·목적으로 라인 색을 정하고, 용기 모양·소재(K8)를 골라 실사 제품 사진용 이미지 프롬프트를 씀
   │   → 이미지 생성 도구로 라인 구성 제품이 함께 놓인 실사 사진을 만듦
   │   결과 화면(K9 템플릿): 라인 카드 → 누르면 상세 카드 (계절·고민·목적·용량·가격 등)
   │
⑥ 가중치 점수 → 출시 추천 순위 (1·2·3위, 후보가 2개면 1·2위)
   │   시장 필요도 · 경쟁 우위 · 성공 가능성 점수를 더해 순위와 이유 제시
   │
⑦ 광고 표현 셀프 체크 + 근거 목록 (K6, 각 지식 파일)
   ↓
[출력] 디자인된 화면: 라인 후보 2~3개의 실사 제품 이미지 카드 + 출시 추천 순위
```

## 출력 양식: 디자인된 화면

결과는 글이 아니라 **실사 제품 이미지가 보이는 화면**으로 나와요. 화면은 Claude 프로젝트의 **아티팩트(HTML 화면)**, 제품 사진은 **이미지 생성 도구**로 만들어요 (아래 "실사 이미지 만드는 방법").

### 화면 1: 라인 카드 (처음 보이는 화면)

```
┌──────────────────────────────────────────────────────────────┐
│  [봄] 시즌 제품 아이디어                 기후 이슈: 황사 · 일교차 · 자외선 │
├───────────────────┬───────────────────┬──────────────────────┤
│  🥇 1위            │  🥈 2위            │  🥉 3위               │
│  ┌─────────────┐  │  ┌─────────────┐  │  ┌─────────────┐     │
│  │ 토너 세럼 크림 │  │ 토너  젤크림  │  │ 토너 세럼 크림 │     │
│  │ (실사 제품 사진)│  │ (실사 제품 사진)│  │ (실사 제품 사진)│     │
│  │ 라인 색으로 칠함│  │              │  │              │     │
│  └─────────────┘  │  └─────────────┘  │  └─────────────┘     │
│  오미자 장벽 보습   │  작약 톤 라인      │  감초 진정 라인        │
│  ● 로즈 베이지      │  ● 피오니 핑크     │  ● 세이지 그린         │
│  [자세히 보기]      │  [자세히 보기]      │  [자세히 보기]          │
└───────────────────┴───────────────────┴──────────────────────┘
```

- 라인마다 **1차 출시 구성 제품을 실제 용기 모양으로** 보여줘요 (토너 = 병, 세럼 = 스포이드 병, 크림 = 단지, 로션 = 펌프 병, 미스트 = 스프레이 병)
- 용기·라벨 색은 라인 색, 라벨에는 브랜드명과 제품명이 들어가요
- 후보가 2개면 카드도 2개예요

### 화면 2: 상세 카드 (카드를 누르면 열림)

```
┌──────────────────────────────────────────────────────────┐
│  (큰 실사 제품 사진)      오미자 장벽 보습 라인     🥇 1위 · ○○점 │
│                          ─────────────────────────────── │
│                          추천 계절   봄                     │
│                          피부 고민   일교차·건조한 바람으로 당김 │
│                          피부 목적   민감·장벽 · ❌ 일반 화장품  │
│                          대표 약재   오미자 (향 약 · 경북 40.7%)│
│  ● 라인 색  #D9B8AE       ─────────────────────────────── │
│  ● 보조 색  #F4ECE6       출시 구성                          │
│  소재: 무광 유리           토너 200ml   15,000원 (ml당 75원)  │
│                          세럼  50ml   19,000원 (ml당 380원) │
│                          크림  50ml   19,000원 (ml당 380원) │
│                          2차 확장: 미스트                   │
│                          ─────────────────────────────── │
│                          순위 근거  시장 필요도 · 경쟁 우위 · 성공 가능성 │
│                          광고 표현 체크 ✅   근거 보기 ▾       │
└──────────────────────────────────────────────────────────┘
```

- 위 칸에 들어가는 내용은 아래 **A~D 데이터**예요. 화면 배치는 팀이 만든 템플릿(K9)을 그대로 써서 매번 같은 모양으로 나와요
- 점수(○○점)는 가중치로 계산한 값이 들어가요. 위 숫자는 아래 봄 예시와 같은 형식 예시예요
- "오미자 흔적 라인"처럼 제품명에 '흔적'을 쓰려면 **미백 기능성 보고 제품**이어야 하고 명사로만 써요 (K6 팀 결정 조건). 장벽 보습 라인 같은 일반 화장품에는 쓰지 않아요

### 색과 디자인을 정하는 순서

1. **라인 색:** 대표 약재의 색에서 시작해 피부 목적으로 조정 (예: 오미자 열매의 붉은색 → 톤 라인이라 채도를 낮춘 로즈 베이지)
2. **보조 색:** 브랜드 기본 색(K1)과 어울리는 밝은 색 1개
3. **용기:** 제품 유형별 기본 모양(K8)에 라인 색을 입힘. 소재(무광 유리, 반투명 플라스틱 등)는 브랜드 톤에서 고름
4. **라벨:** 브랜드명 + 제품명 (제품명 규칙 K1, 금지어 확인 K6)
5. **실사 이미지 프롬프트:** 1~4의 값으로 영어 프롬프트를 씀 (예: 라인 구성 제품 3개, 색, 소재, 대표 약재 소품, 배경, 조명)

### 실사 이미지 만드는 방법

| 방법 | 어떻게 | 장단점 |
|---|---|---|
| A. 반자동 (지금 바로 가능) | 에이전트가 화면에 **이미지 프롬프트**를 쓰고 → 사람이 이미지 생성 AI(ChatGPT 이미지, Adobe Firefly, Canva AI 등)에 넣어 사진을 만들고 → 화면 이미지 칸에 넣음 | 도구를 골라 쓸 수 있어요. 한 번 더 손이 가요 |
| B. 자동 | Claude 프로젝트에 이미지 생성이 되는 커넥터를 연결해 에이전트가 사진까지 만들게 함 | 시연이 매끄러워요. 팀 계정에서 쓸 수 있는 커넥터인지 확인 필요 |

- 생성 이미지에는 실제 브랜드 로고·제품이 들어가지 않게 해요 (경쟁사 제품 모방 금지). 라벨 글자는 이미지 AI가 틀리게 쓰는 경우가 많아서, 화면에서 라벨 글자를 따로 얹는 방법도 있어요
- 레이아웃 참고용 그림 시안: `research/LJH_K9_결과화면_시안.html` (SVG 그림 버전. 실사 사진이 들어갈 자리를 보여 줌)

### 화면에 들어가는 데이터

**A. 이 계절의 피부 고민 후보** (3~5개, 기후 이슈와 연결)

| 기후 이슈 | 피부 고민 | 피부 목적 | 근거 |
|---|---|---|---|

**B. 라인 후보 3개 (안 되면 2개)** (라인마다 한 블록. 2개면 3개가 안 된 이유 한 줄)

| 항목 | 내용 |
|---|---|
| 라인 이름 (가칭) | 브랜드명 + 대표 약재 + 피부 고민 + 유형 규칙 |
| 해결하는 고민 / 피부 목적 | A의 고민 중 무엇, 기능성 여부 (✅ 심사·보고 필요 / ❌ 일반) |
| 대표 약재와 이유 | 향 세기, 경북 산지 가산점, 경쟁사 선점 정도 |
| 1차 출시 구성 | 제품 유형·용량 (예: 토너 200ml, 크림 50ml) / 2차 확장 후보 |
| 출시가 | 제품별 정가, ml당 정가, 계산 근거 (시장 기준 / 원가 기준) |
| 디자인 | 라인 색·보조 색(HEX), 용기 모양·소재, 라벨 문구, **실사 이미지 프롬프트** → 화면의 제품 사진에 쓰임 |

**C. 출시 추천 순위** (후보 수만큼 1·2·3위 또는 1·2위)

| 순위 | 라인 | 시장 필요도 | 경쟁 우위 | 성공 가능성 | 합계 | 추천 이유 한 줄 |
|---|---|---|---|---|---|---|

**D. 광고 표현 체크 결과 / 근거** (지식 파일에 없으면 "자료 확인 필요")

## 가중치 (우선순위) 기준

팀이 정할 값이에요. 아래는 지금 있는 자료로 바로 매길 수 있게 만든 **제안안**이에요.

| 기준 | 비중 (제안) | 무엇을 보나 | 점수 근거 (지식 파일) |
|---|---|---|---|
| **시장 필요도** | 40% | 그 계절에 이 고민이 얼마나 크고 흔한가 | K4 기후 이슈 강도, 고객 인사이트(리뷰·질문글 언급), 올리브영 상위 제품의 목적 분포 |
| **경쟁 우위** | 30% | 경쟁이 비어 있거나, 우리가 이길 수 있는가 | K3 선점 정도 (약함 5 · 보통 3 · 강함 1점, 강함이면 차별화 이유 필수), 한방 브랜드 제품 유무 |
| **성공 가능성** | 30% | 우리가 잘 만들고 팔 수 있는가 | 출시가가 중저가 범위 안인가(K5), 향 부담(K3 향 세기), 경북 산지 가산점, 기능성이면 보고(고시 성분)로 가능한가 |

- 점수는 기준마다 1~5점 × 비중 → 100점 만점으로 환산해요.

**비중 정하는 방법 (40/30/30은 임시값)**
1. **근거로 시작값 잡기:** 2030 화장품 구매 기준 조사에서 기능 30.2%, 가성비 29.4%, 브랜드 이미지 3.4%였어요 (`05_고객인사이트_종합.md`, 어피티 구독자 351명이라 표본 작음). 가격·만들기 쉬움이 들어간 성공 가능성을 30% 안팎으로 둔 근거예요. 더 큰 표본의 조사로 확인 필요
2. **3명이 따로 매기고 평균 내기:** 세 기준 중 무엇이 더 중요한지 각자 100점을 나눠 적고 평균을 내요
3. **흔들림 확인:** 같은 입력(4계절)을 비중 3가지(40/30/30, 34/33/33, 30/30/40)로 돌려서 순위가 크게 바뀌는지 봐요. 순위가 그대로면 비중 결정이 결과에 큰 영향이 없다는 뜻이에요
4. **성공 가능성 점수 세부 기준 정하기:** 비중보다 점수 기준이 더 중요해요. 예를 들어 출시가가 중저가 범위 안이면 2점, 향 부담 약·거의 없음이면 1점, 경북 산지면 1점, 기능성 보고로 가능하거나 일반 화장품이면 1점 (합계 5점)
- 에이전트는 점수만 쓰지 않고 **기준마다 이유를 한 줄** 적어요. 근거가 없는 칸은 "자료 확인 필요"로 두고 점수를 매기지 않아요.

## 출력 예시: 봄 (형식 예시)
