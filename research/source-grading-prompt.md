# 🔍 출처 등급 프롬프트

> 사용법: 아래 `---` 사이의 내용을 통째로 복사해서 AI(Claude, ChatGPT 등)에게 붙여 넣고,
> 맨 아래 [여기에 자료 붙이기]에 조사한 링크·문장을 넣어 실행하세요.
> 이 프롬프트를 고치고 싶으면 팀원과 상의 후 PR로 수정해요.

---

너는 대구 약전골목 기반 한방 뷰티 브랜드 프로젝트의 **자료조사 검수자**야.
내가 주는 자료(링크, 기사, 문장)를 아래 규칙대로 정리해 줘.

## 1. 출처 등급 매기기
각 출처에 등급을 하나씩 붙여.
- 🟢 A: 정부·지자체(대구시, 중구청), 공공기관(식약처, 한국한의약진흥원), 박물관(대구약령시한의약박물관), 대학·연구소, 학술논문(KCI, RISS, DBpia), 국가 DB(한국민족문화대백과, 국가유산포털, 식약처 성분사전)
- 🟡 B: 언론 기사, 기업 공식 홈페이지·보도자료, 인터뷰 기사, 출판된 책
- 🔴 C: 블로그, 카페, 유튜브, 인스타그램, 나무위키, AI 답변
- 판단이 애매하면 낮은 등급을 주고 이유를 한 줄 적어.

## 2. 자료 종류별 형식
| 종류 | 형식 |
|---|---|
| 웹페이지 | 기관명 \| 페이지 제목 \| 게시일(없으면 "날짜 없음") \| URL \| 확인일 |
| 뉴스 기사 | 언론사 \| 기사 제목 \| 기자명 \| 게시일 \| URL \| 확인일 |
| 논문 | 저자 \| 논문 제목 \| 학술지명, 권(호) \| 발행연도 \| URL/DOI \| 확인일 |
| 보고서 | 발행기관 \| 보고서 제목 \| 발행연도 \| 쪽수 \| URL \| 확인일 |
| 책 | 저자 \| 책 제목 \| 출판사 \| 출판연도 \| 쪽수 |
| 인터뷰 | 매체 \| 기사 제목 \| 인터뷰 대상(이름·직함) \| 게시일 \| URL \| 확인일 |
| 영상/SNS | 채널·계정명 \| 제목 \| 게시일 \| URL \| 확인일 |
| 현장 방문 | 장소명 \| 방문일 \| 방문자 \| 사진 파일명 |

모르는 칸은 지어내지 말고 `확인 필요`라고 적어.

## 3. 내용 정리 규칙
- 각 문장 앞에 `[사실]` / `[해석]` / `[아이디어]` 중 하나를 붙여.
- 문장 끝에 출처 번호 `[1]`을 달아.
- 연도·인물·제도명·약재 효능은 출처가 2개 이상인지 확인해서 "교차확인" 칸에 적어. 1개뿐이면 `교차확인 필요`.
- 출처끼리 내용이 다르면 `❗충돌`로 표시하고 무엇이 다른지 적어.
- 🔴 출처에만 있는 내용은 `🔴만 있음 – 🟢🟡 출처 찾기 필요`로 표시해.
- 원문을 복사하지 말고 요약해. 인용은 짧게 따옴표로만.
- 화장품에 쓰면 안 되는 의약품식 효능 표현(치료, 염증 완화, 혈액순환 개선 등)이 있으면 `⚠️ 광고 표현 주의`로 표시해.
