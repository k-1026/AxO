## 1순위: CHAHAR / 차하르 (가칭)

[아이디어] 차하르는 '넷'이라는 뜻에서 출발한 이름으로, 네 계절을 상징합니다. 계절이 달라질 때 피부 관리도 그 변화에 맞춰야 한다는 생각에서 출발했고, 계절과 피부 고민을 고르면 그에 맞는 한방 기초라인과 관리 루틴을 추천하는 에이전트로 의미를 구현하고자 했습니다.

### 어원 확인 결과
- [사실] 페르시아어 **chahār(چهار)** = '넷(4)'. 이란 페르시아어(파르시어, 다리어 등)에서 쓰는 말이에요. 출처: [Sublearn 페르시아어 사전](https://sublearn.com/ko/learn/fa/vocabulary/chhardh), [Wiktionary 페르시아어 '4'](https://ko.wiktionary.org/wiki/%D8%A8%D9%87%D8%A7%D8%B1)
- [사실] 페르시아어 요일 '차르샨베(수요일)'도 chahar(넷)와 shanbe(토요일)에서 왔다고 설명돼요. 출처: 위와 같은 사전 자료 (확인 필요)
- [확인 필요] 중국 내몽골의 **차하르(Chahar)**는 몽골 부족명(Chahar Mongols)이에요. 이 몽골어 이름이 페르시아어 '넷'에서 왔는지는 확인되지 않았어요.
- [확인 필요] 아프가니스탄의 아이마크족이 chahar라는 이름으로 알려졌다는 자료가 있어, '넷'과 연결될 가능성은 있어요. 확실한 근거가 아니에요.
- **언어 답변**: 페르시아어(이란·아프가니스탄 등에서 쓰는 페르시아계 언어)가 기본이에요. 몽골 부족명으로 쓰일 때는 몽골어 맥락이에요.

## 2순위: 청향(淸香)

### 원문과 뜻
- **원문**: 「청향(淸香)은 잔에 지고, 낙홍(落紅)은 옷새 진다」
- **출처**: 정극인, 《상춘곡(賞春曲)》, 조선 전기 가사 (성종 연간 작품으로 소개됨). [전북일보 기사](https://www.jjan.kr/article/20190612678087), [상춘곡 해설(happycampus)](https://www.happycampus.com/doc/27588402)
- [확인 필요] 원문 표기와 주석은 상춘곡 주석본으로 한 번 더 확인 권장

### 구절 풀이 [사실 + 해석]
- **청향(淸香)**: 맑은 향기 [사실]
- **잔에 지고**: 향기가 술잔에 어린다 [해석] (지다 = 떨어지다·내려앉다)
- **낙홍(落紅)**: 떨어지는 붉은 꽃잎. 落(떨어질 낙) · 紅(붉을 홍) [사실]
- **옷새 진다**: 옷에 떨어진다 [해석]. '옷새'를 단어별로 풀이한 자료는 찾지 못했어요. [확인 필요]
- 전체 장면: 봄바람이 불어 들을 건너오니, 맑은 향기는 술잔에 어리고 붉은 꽃잎은 옷에 떨어진다. 자연 속에서 사람과 자연이 하나가 되는 경지를 그린 구절이에요 [해석, 출처: 상춘곡 해설 기사]

### 청향 구현 아이디어 [아이디어]
1. **시각**: 청자색·옥색 계열 바탕에 분홍 꽃잎 한 장. 기본 라인의 분홍 유리 톤과 이어져요.
2. **용기**: 술잔 모양의 작은 병이나 뚜껑. 잔에 향이 어린다는 이미지를 살려요.
3. **라벨·패키지**: 꽃잎이 옷에 떨어지는 장면을 아주 작게 그려 넣어요. 제품 설명은 짧게.
4. **향 표현**: 팀 기준은 향 세기 "약 또는 거의 없음"이에요. 그래서 실제 향을 세게 주기보다 **맑은 향을 이미지와 문장으로 전달**하는 방식이 맞아요. [확인 필요: 팀 기준과 충돌 여부 논의]
5. **카피**: 상춘곡의 봄 분위기를 살린 짧은 문장. 예: "봄바람 따라 맑은 향이 잔에 어리는 순간." 효능 표현은 쓰지 않아요.
6. **에이전트 연결**: 봄 계절을 고르면 "봄 한 잔" 루틴처럼 추천 흐름을 만들 수 있어요. 봄 라인 구성(진정 라인 등)과 연결 가능. 원료 후보 작약은 팀 조사 문서의 원료 목록에 있어요 [사실: 한방브랜드_라인구성 문서 기준].
7. **원문 사용 원칙**: 짧은 인용만 쓰고 전체를 옮기지 않아요.

## 차하르 vs 낙홍 비교

낙홍(落紅)은 청향 원문 속 구절이에요. 두 이름을 같은 가치 기준으로 비교했어요.

| 항목 | 차하르 (CHAHAR) | 낙홍 (落紅) |
|---|---|---|
| 뜻 | 페르시아어 '넷(4)' [사실] | 떨어지는 붉은 꽃잎 [사실] |
| 언어·출처 | 페르시아계 언어, 몽골 부족명 연상 [사실/확인 필요] | 한국 고전 가사《상춘곡》 [사실] |
| 계절 연결 | 네 계절 (팀 콘셉트) [아이디어] | 봄 꽃이 지는 장면 [해석] |
| 한국성 | 약함. 외래어 느낌 | 강함. 한국 고전 기반 |
| 발음·기억 | 짧고 외래어처럼 부드러움 | 한자 두 글자, 발음이 낯설 수 있음 |
| 주의점 | 몽골 지명 차하르와 연상될 수 있음 [확인 필요] | "落(떨어질 낙)"이라 **쇠퇴·끝** 이미지로 읽힐 수 있음 |
| 영문 표기 | CHAHAR | 영문 표기 정해야 함 (Nakhong 등) [확인 필요] |
| 광고 원칙 | 이름 자체에 효능 없음 | 이름 자체에 효능 없음 |

**판단 메모 [해석]**: 한방 브랜드의 한국성과 고전 이야기를 원하면 낙홍이나 청향이 맞아요. 다만 낙홍은 "떨어짐" 이미지가 상품명으로 부담될 수 있어요. 차하르는 계절 4개 콘셉트를 가장 잘 설명하지만, 어원이 외국어라서 한방 정체성과 맞추려면 설명이 더 필요해요.
