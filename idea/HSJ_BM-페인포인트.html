기획의 연결이 어렵다.

핵심 문제 가설

“약재 조사부터 선택 근거 검토,
제품 라인 기획안 정리까지 시간이 많이 든다.”

BM이 겪는 6가지 어려움

우선 해결 제안: 02 · 03 · 06
01 / NEEDS

다음 시즌의 고객 니즈를
미리 정하기 어렵다

여름이라는 조건만으로는 타깃의
피지·속당김·열감 중 무엇을
우선할지 결정하기 어렵다.

에이전트 →시즌·타깃·지역별
우선 피부 고민과 선정 이유
02 / EVIDENCE우선 해결

약재의 전통 효능과
화장품 근거를 잇기 어렵다

전통적 설명과 실제 화장품 적용
연구가 혼재한다. 부위·추출 방식이
다른 원료를 비교하기도 어렵다.

에이전트 →원료 형태·사용 부위·연구 기반
근거 수준별 약재 후보 비교
03 / LINEUP우선 해결

원료 후보를 제품 라인으로
구체화하기 어렵다

세럼·크림·클렌저 중 어디에 적용할지,
각 제품의 역할과 제형을 어떻게
나눌지 결정해야 한다.

에이전트 →핵심·보조 제품의 역할을 나눈
제품 구성·제형·사용 순서 초안
04 / DIFFERENTIATION

검증된 원료를 고르면
경쟁사와 비슷해진다

익숙한 원료는 경쟁 제품이 많고,
새로운 원료는 효능 근거와
공급 정보를 찾기 어렵다.

에이전트 →경쟁사 사용 현황을 포함한
기존·신규 원료의 장단점 비교
05 / FEASIBILITY

제조 검토에서 기획을
다시 바꿔야 한다

향·색·제형 적합성·단가·수급을
뒤늦게 확인하면 원료뿐 아니라
콘셉트와 제품 구성도 수정된다.

에이전트 →확보된 공급사 자료에 기반한
제조 검토 항목·대체 원료 표시
06 / BRIEF우선 해결

선택 이유를 설명하는
기획서 작성이 반복된다

내부 승인과 제조사 협의를 위해
계절 적합성·효능 근거·차별성을
여러 자료에서 다시 모아야 한다.

에이전트 →출처와 후보 선정·제외 이유를 담은
제품 개발 의뢰서 초안 생성

우선순위는 현재 에이전트 구상과의 적합성 기준이며, 불편의 빈도와 심각도는 실제 BM 인터뷰로 검증해야 합니다.

AGENT ROLE

계절 선택을
라인 기획 초안으로.

시즌과 타깃에 맞는 약재를 비교하고,
설명 가능한 제품 라인으로 연결합니다.

01
기획 조건 입력

계절 · 타깃 · 가격대 · 출시 시점

02
약재 후보 비교

피부 고민 · 근거 · 경쟁 제품 검토

03
제품 라인 제안

핵심·보조 제품 · 제형 · 사용 순서

04
개발 의뢰서 정리

선정 이유 · 출처 · 제조사 확인 사항

최종 처방과 원료 적용은 제조사·연구 담당자 검토.
근거가 없는 조건은 ‘추가 확인’으로 표시.
추천에 필요한 입력
계절 선택타깃 피부 타입주요 피부 고민목표 가격대출시 시점판매 지역

계절을 시작점으로, 고객과 제품 조건을 더해 추천을 구체화합니다.

가치 검증 지표 · 목표 방향
↓조사·기획 시간동일 과제의 사용 전후 비교
↑근거 확보 후보 수출처·적용 범위 확인 기준
↓전달 전 수정 횟수근거·조건 누락 보완 비교
