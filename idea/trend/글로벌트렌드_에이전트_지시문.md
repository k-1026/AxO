# 글로벌 뷰티 트렌드 서브 에이전트 지시문

> 출처 목록: [sources.json](sources.json) · 결과 파일: [beauty_trends.json](beauty_trends.json) (출시 기획실 화면이 읽는 파일)
> 출처 상태 확인 스크립트: [beauty_sources_check.js](beauty_sources_check.js)

## 📌 한 줄 요약
서브 에이전트는 `sources.json`의 출처 11곳을 읽고, 열리는 공개 자료만 요약해 `beauty_trends.json`에 쌓아요. 출시 기획실 화면은 이 파일로 계절별 "트렌드 한마디"를 보여 줘요.

## 실행 순서
1. **출처 상태 확인**
   - `node idea/trend/beauty_sources_check.js` 를 실행해요.
   - 출처마다 열림(checked) / 막힘(unavailable)이 `sourceChecks`에 기록돼요.
2. **열린 출처만 읽기**
   - `status: "checked"`인 출처의 `url`과 `allowedHosts` 안의 페이지만 읽어요.
   - 막힌 출처는 다시 시도하거나 우회하지 않고, 결과에 "확인 못 함"으로 남겨요.
3. **새 자료 고르기**
   - **최근 신호:** 게시일이 90일(`signalLookbackDays`) 안인 자료
   - **배경 자료:** 연간 보고서처럼 400일(`backgroundLookbackDays`) 안인 자료. `background: true`를 붙여요.
4. **`items`에 한 건씩 추가하기**
   - 이미 있는 `url`은 다시 넣지 않아요.
   - 아래 형식을 지켜요.
5. **`insights` 갱신하기**
   - 계절별 기획 방향을 한 줄(`line`)과 검토 팁(`tip`)으로 써요.
   - 근거가 된 item의 `id`를 `evidenceIds`에 적어요.
   - 근거가 없는 계절은 바꾸지 않아요.

## item 형식
```json
{
  "id": "출처id-글번호",
  "source": "sources.json의 name",
  "kind": "아래 신호 종류 중 하나",
  "title": "원문 제목 (그대로)",
  "url": "원문 주소",
  "publishedAt": "YYYY-MM-DD (모르면 null)",
  "checkedAt": "확인한 시각 (ISO)",
  "region": "국가·지역 (예: 한국, 미국, 일본, 글로벌)",
  "period": "자료가 다루는 기간 (예: 2026년 1~6월)",
  "background": false,
  "summary": "원문 복사 없이 2문장 이내 요약 + 이 자료로 말할 수 없는 것",
  "tags": ["제형·성분·피부 고민 키워드"]
}
```

## 신호 종류 (kind): 섞어서 말하지 않기
| kind | 출처 예 | 말할 수 있는 것 | 말하면 안 되는 것 |
|---|---|---|---|
| 검색 관심 | Google Trends | 관심이 늘거나 줄었다 | 검색량·판매량 |
| 소셜·검색 분석 | Spate | 관심이 커지는 성분·고민·제형 | 실제 구매 |
| 신제품·시장 전망 | Mintel · GNPD | 어떤 콘셉트·표현이 늘고 있다 | 우리 제품의 성공 |
| 구매 데이터 | NielsenIQ | 조사 국가·채널·기간 안의 구매 흐름 | 다른 국가·채널로 일반화 |
| 시장·채널 전망 | McKinsey | 타깃 국가·가격대·채널 배경 | 실시간 인기 |
| 업계 기사·제품 사례 | Cosmetics Business, 장업신문, 올리브영 | 이런 제품·움직임이 있다 | 시장 전체 선호 (기업 홍보와 구분) |
| 전시·제품 혁신 | CosmoTrends | 새 제형·패키지 아이디어 | 판매 성공 |
| 시각 트렌드 | Pinterest Predicts | 색감·패키지·비주얼 방향 | 피부 효능 |
| 리뷰·랭킹 | @cosme | 일본 시장의 제품 평가 | 한국 시장 판매 |

## 지켜야 할 것
- 공개·접근 가능한 자료만 써요. 로그인·유료·차단 페이지는 상태만 기록하고 우회하지 않아요.
- 원문을 복사하지 않고 요약해요. 인용이 꼭 필요하면 15단어 안으로 따옴표를 써요.
- 숫자는 원문에 있는 그대로만 쓰고, 계산·추정한 숫자는 넣지 않아요.
- 오래된 전망(배경 자료)을 "지금 뜨는 것"이나 "판매 증가"로 바꿔 말하지 않아요.
- "치료", "염증 완화", "재생" 같은 의약품식 표현을 `summary`·`insights`에 쓰지 않아요 (광고 표현 규칙).
- 근거가 없으면 지어내지 않고 비워 둬요.
