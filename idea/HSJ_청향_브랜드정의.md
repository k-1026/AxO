## 1부. 브랜드 기본 정보

| 항목 | 내용 |
|---|---|
| **브랜드명** | 청향(Cheonghyang) — ⚠️ 미확정, 협의 필요 |
| **정체성** | 현대적 한방 스킨케어. 한방을 전통 이미지가 아닌 현대 스킨케어의 언어로 바꾼다 |
| **핵심 타깃** | 20~30대 여성 |
| **출발점** | 대구 약령시 |
| **브랜드 스토리 (한 줄)** | "오래된 약재의 지혜를 오늘의 스킨케어로." |

### 메인 슬로건

> **"청향(淸香)은 잔에 지고, 낙홍(落紅)은 옷새 진다"**
>
> 화창한 봄바람이 문득 불어 푸른 들을 건너 오니, 맑은 향기는 술잔에 지고, 붉은 꽃잎은 옷에 떨어진다.

**출처:** 조선 전기 가사 문학의 효시인 정극인(丁克仁)의 작품 《상춘곡(賞春曲)》에 나오는 구절

### 브랜드 설명

- 한약재를 원료를 쓰지만 맑은 향기를 가진
- 작약 꽃잎 한 방울
- 대구 약전골목의 지식과 정신을 계승하여 탄생
- 우수한 한약재 원료만을 선별해 여리고 예민한 피부 고민에 맞도록 케어

## 2부. 예시 초안 (미확정)

### 방향 정리

- **기본:** 깔끔하고 모던한 한방 스킨케어
- **포인트:** 모노톤에 머물지 않고 **포인트 컬러플레이**를 해요
- **확장성:** 나중에 메이크업 제품이 나와도 어색하지 않은 톤

컬러는 슬로건의 두 이미지에서 가져오면 브랜드 이야기와 자연스럽게 이어져요.

| 역할 | 슬로건 속 이미지 | 컬러 예시 |
|---|---|---|
| 베이스 | 맑은 향기(淸香) | 오프화이트, 맑은 회색 |
| 포인트 ① | 붉은 꽃잎(落紅), 작약 | 작약 핑크, 코랄 레드 |
| 포인트 ② | 푸른 들 | 새순 그린, 쑥 그린 |
| 확장용 (메이크업 등) | 약재의 색 | 오미자 레드, 황기 옐로, 당귀 브라운 |

---

### ① 톤앤매너 예시

**말투 원칙**
- **맑고 짧게:** 한 문장에 한 가지 이야기만 해요.
- **한방은 쉽게:** 어려운 한자어는 풀어 쓰고, 약재 이름은 `한글(한자)`로 한 번만 보여 줘요.
- **다정하되 과장하지 않기:** "~해요" 체를 쓰고, 효능을 부풀리지 않아요.
- **계절과 감각의 언어:** 꽃, 바람, 향기, 빛 같은 말로 분위기를 만들어요.

**문장 예시 (5개)**
1. 오늘 피부에 필요한 건 맑은 향 한 방울이에요.
2. 대구 약전골목에서 오래 다뤄 온 약재를, 가볍게 스며드는 제형으로 담았어요.
3. 작약(芍藥) 꽃잎처럼, 여린 피부도 부드럽게 감싸 줄게요.
4. 한방이 무겁다는 생각은 잠시 내려놓으세요. 청향은 봄바람처럼 가벼워요.
5. 매일의 루틴에 작은 컬러 하나, 기분까지 맑아지는 시간이에요.

**피할 표현**
- "치료", "염증 완화", "혈액순환 개선" 같은 의약품식 효능 표현
- "할머니 비법", "궁중 비방"처럼 오래되고 무거운 이미지만 강조하는 말
- 과한 영어 섞기, 지나친 유행어

| **직업** | 서울 IT 회사 UX 디자이너 |
| **피부** | 수부지(수분 부족 지성), 환절기마다 예민해짐 |
| **관심사** | 미니멀 인테리어, 전시 관람, 필라테스, 향(룸 스프레이·향수) |
| **구매 채널** | 올리브영, 브랜드 자사몰, 인스타그램 광고 |
| **한방에 대한 생각** | "피부에 좋다는 건 알지만 패키지가 너무 올드하고 향이 무거워요." |
| **구매 이유** | 성분은 믿을 수 있고, 디자인이 화장대에 두고 싶을 만큼 예뻐서 |
| **불편한 점** | 한약 냄새, 끈적한 제형, 금색·자주색 위주의 전통적 디자인 |
| **청향이 줄 수 있는 것** | 맑은 향, 가벼운 제형, 모던한 디자인에 작약 핑크 같은 포인트 컬러 |

## ⚠️ 광고 표현 체크

- **"여리고 예민한 피부 고민에 맞도록 케어"** → 화장품 표현 범위 안에 있어요. 다만 상세페이지에 쓸 때는 "진정", "개선" 같은 말을 붙이지 않는 게 안전해요.
- **톤앤매너 예시 문장** → 의약품식 효능 표현은 넣지 않았어요.
