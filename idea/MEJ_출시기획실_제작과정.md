## 🧱 사이트 구성 (최종)

1. **상단 메뉴:** CHAHAR(가칭) · 기본 라인 · 지난 컬렉션 · 출시 기획실
2. **계절 선택 + 실시간 뷰티 트렌드:** 봄·여름·가을·겨울, 트렌드 한마디, ↻ 새로고침, 근거 보기(실시간 신호·업계 사례·배경 자료 3칸)
3. **출시 기획실:** 프리셋(체크리스트 기본·이번 시즌 바로·우리다움 먼저·🎯 빈자리 공략·고민 해결 먼저·직접 고르기) → 후보 순위 근거 버튼(★ 비중) → 필수 통과 조건
4. **결과:** Top 3 카드 + 다른 후보 표 (확인 안 된 칸은 점수 범위로 표시)
5. **상세 화면:** 용기 사진·색상 변경 전후·패키지 팔레트 / 구분·대표 약재·쓸 수 있는 말 / 이 조합을 추천한 이유(키워드) / 이런 고객에게 권해 보세요(페르소나) / 출시 구성(용량·정가·ml당) / 필수 통과 조건 / 출시 순위 근거
6. **기본 라인 한눈에 보기:** 5개 제품군, 7가지 용기 사진을 같은 배율로

## 📐 지켜 온 규칙
- **광고 표현:** "치료·염증 완화·재생" 같은 의약품식 표현은 쓰지 않고, 광고 표현 규칙의 "쓸 수 있는 말"만 사용
- **점수:** 점수는 성공 확률이 아님. 자료가 없는 칸은 0점이 아니라 **점수 범위(하한~상한)**로 표시
- **가격:** 정가는 가격 기준표(K5)의 중저가 ml당 정가 범위 안의 예시값. 원가 자료가 없어 "수익성" 기준은 꺼 둠
- **브랜드:** 브랜드명은 미정 (CHAHAR는 가칭). 이름·페르소나는 팀이 정함
- **저작권:** 라이선스 없는 캐릭터(산리오 등)는 쓰지 않음

## ❓ 아직 남은 것
- 트렌드 서브 에이전트가 새 출처를 아직 요약 항목으로 바꾸지 못함 (일부 출처 접속 차단: Google Trends, @cosme, 올리브영 랭킹, McKinsey)
- 네이버 데이터랩 API 키는 팀이 발급해야 함
- 용기 사진 자르는 영역은 눈으로 맞춘 값
- 점수 구간과 ★ 비중은 팀 합의 필요
